So funktioniert: JWT dekodieren & prüfen

Fügen Sie ein Token ein und sehen Sie Header und Payload als formatiertes JSON, mit in Daten umgewandelten Zeiten für Ausstellung, frühesten Beginn und Ablauf und einem klaren Status „abgelaufen“ oder „gültig“. Geben Sie das Geheimnis ein, um eine HS256-, HS384- oder HS512-Signatur zu prüfen. Warnungen kennzeichnen unsignierte Tokens (alg none) und Tokens, die nie ablaufen.

Ein JWT besteht aus drei durch Punkte getrennten Base64URL-Teilen: Header.Payload.Signatur. Die ersten beiden werden in Ihrem Browser dekodiert und als JSON geparst, das Token wird also nie hochgeladen, was wichtig ist, weil Tokens Zugang gewähren. Bei HMAC-Algorithmen wird die Signatur mit Web Crypto über „Header.Payload“ neu berechnet und mit der im Token verglichen. Public-Key-Algorithmen (RS256, ES256) lassen sich ohne den Schlüssel nicht verifizieren und werden hier nicht geprüft. Das Dekodieren beweist keine Echtheit, und ein JWT ist nur signiert, nicht verschlüsselt: Legen Sie keine Geheimnisse in die Payload.

So benutzt du es

  1. Fügen Sie das JWT ein (ein vorangestelltes „Bearer “ ist in Ordnung).

  2. Lesen Sie Header, Payload und Zeit-Claims ab.

  3. Geben Sie optional das Geheimnis ein, um eine HMAC-Signatur zu prüfen.

Häufige Fragen

Ist es sicher, ein JWT hier einzufügen?

Das Token wird in Ihrem Browser dekodiert und nie gesendet. Behandeln Sie Tokens dennoch wie Passwörter und vermeiden Sie es, Produktions-Tokens in Werkzeuge einzufügen, denen Sie nicht vertrauen.

Kann jeder die Payload eines JWT lesen?

Ja. Die Payload ist nur kodiert, nicht verschlüsselt. Jeder, der das Token hat, kann sie lesen.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
