Video-Geschwindigkeit ändern (Zeitlupe und Zeitraffer)

Ein Video verlangsamen oder beschleunigen, der Ton folgt mit.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Video-Geschwindigkeit ändern (Zeitlupe und Zeitraffer)

Geben Sie eine Geschwindigkeit von 0,1× bis 20× ein: 0,5 spielt mit halber Geschwindigkeit (Zeitlupe), 2 doppelt so schnell, 8 macht aus einer langen Aufnahme einen Zeitraffer. Der Ton wird auf dieselbe Geschwindigkeit angepasst, ohne seine Tonhöhe zu ändern.

Das Bildtiming wird mit dem setpts-Filter von FFmpeg geändert, der Ton mit verketteten atempo-Filtern (jede Stufe schafft nur Faktoren zwischen 0,5 und 2, extreme Geschwindigkeiten nutzen also mehrere). Zeitlupe kann keine neuen Bilder erfinden, ein sehr langsamer Clip kann daher ruckeln. Das Video wird von FFmpeg verarbeitet, dem Standard-Open-Source-Videowerkzeug, das zu WebAssembly kompiliert wurde und in Ihrem Browser läuft. Beim ersten Mal wird die Engine geladen (etwa 31 MB), die Ihr Browser dann behält. Nichts wird hochgeladen. Alles geschieht im Arbeitsspeicher Ihres Browsers, sehr große Videos (mehrere Gigabyte) oder lange 4K-Clips können daher auf einem Telefon oder älteren Rechner scheitern; probieren Sie dann einen kürzeren oder kleineren Clip.

So benutzt du es

  1. Ziehen Sie das Video hinein.

  2. Geben Sie die Geschwindigkeit ein (unter 1 = langsamer, über 1 = schneller).

  3. Drücken Sie „Geschwindigkeit ändern“ und laden Sie herunter.

Häufige Fragen

Klingt die Stimme wie ein Chipmunk?

Nein. Die Tonhöhe bleibt erhalten, Stimmen klingen bei mäßigen Geschwindigkeiten also natürlich; bei extremen Geschwindigkeiten wird Sprache schwer verständlich.

Kann ich nur einen Teil eines Videos beschleunigen?

Schneiden Sie den Teil mit dem Video-Schneider heraus, ändern Sie hier sein Tempo und fügen Sie die Stücke mit dem Video-Verbinder zusammen.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
