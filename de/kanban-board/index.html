Kanban-Board (To do, Doing, Done)

Ein persönliches Drei-Spalten-Board mit Drag-and-drop, lokal gespeichert.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Kanban-Board (To do, Doing, Done)

Skizzieren Sie Ihre Arbeit als Karten in drei Spalten: was wartet, was Sie gerade tun und was erledigt ist. Ziehen Sie Karten zwischen Spalten (oder nutzen Sie die Pfeile), fügen Sie Karten durch Tippen hinzu und kopieren Sie das Board als Markdown für ein Status-Update.

Das Board ist eine kleine Datenstruktur aus Spalten und Karten, nach jeder Änderung im localStorage gespeichert und mit dem nativen Drag-and-drop des Browsers plus Pfeilschaltflächen für Tastaturnutzer gezeichnet. Es ist bewusst ein persönliches Werkzeug: Nichts wird geteilt oder synchronisiert, was auch heißt, dass es keine Anmeldung und keine Daten auf einem Server gibt. Die Zahl der Karten in „Doing“ zu begrenzen ist die Kern-Kanban-Gewohnheit, die dieses einfache Board sichtbar macht.

So benutzt du es

  1. Fügen Sie Karten in der Spalte „To do“ hinzu.

  2. Ziehen Sie sie nach „Doing“ und „Done“ (oder nutzen Sie die Pfeile).

  3. Kopieren Sie das Board als Markdown, wenn Sie berichten müssen.

Häufige Fragen

Können mehrere Personen das Board nutzen?

Nein, es wird in Ihrem eigenen Browser gespeichert. Es dient der persönlichen Planung.

Wie verschiebe ich Karten mit der Tastatur?

Mit Tab zu einer Karte und die Schaltflächen ← und → nutzen.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
