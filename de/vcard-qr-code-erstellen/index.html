So funktioniert: vCard-QR-Code (Kontakt-QR) erstellen

Legen Sie Name, Firma, Telefonnummern, E-Mail, Website und Adresse in einen QR-Code für Visitenkarten, E-Mail-Signaturen oder Konferenzausweise. Das Scannen bietet an, den Kontakt direkt im Adressbuch des Handys zu speichern.

Der Code enthält einen vCard-3.0-Datensatz (BEGIN:VCARD … END:VCARD) mit strukturiertem Namen (N), formatiertem Namen (FN), Organisation, Titel, Telefonnummern (nur Ziffern, mit internationalem +), E-Mail, URL, Geschäftsadresse und Notiz. Sonderzeichen wie Kommas, Semikolons und Zeilenumbrüche werden wie vom Standard verlangt maskiert. Je mehr Felder Sie ausfüllen, desto dichter wird der Code und desto größer muss er gedruckt werden, um zuverlässig zu scannen; weniger Felder bedeuten leichteres Scannen. Alles wird lokal erzeugt.

So benutzt du es

  1. Füllen Sie die Felder aus, die Sie teilen möchten.

  2. Laden Sie den QR-Code herunter oder drucken Sie ihn.

  3. Scannen Sie ihn mit einem Handy, um zu testen, wie der Kontakt aussieht.

Häufige Fragen

Wie groß soll der QR-Code auf einer Visitenkarte sein?

Mindestens 2 × 2 cm. Halten Sie den Inhalt kurz (Name, Telefon, E-Mail) für einen Code, der auch klein leicht scannt.

Wird der Kontakt online gespeichert?

Nein. Die Daten stecken im Code selbst, er funktioniert also ewig, und es ist kein Dienst beteiligt.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
