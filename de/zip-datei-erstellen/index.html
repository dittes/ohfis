So funktioniert: ZIP-Datei erstellen (Dateien und Ordner komprimieren)

Fügen Sie Dateien hinzu, ziehen Sie viele auf einmal hinein oder wählen Sie einen ganzen Ordner (seine Unterordner bleiben erhalten), wählen Sie die Kompressionsstufe und laden Sie eine ZIP-Datei mit dem gewünschten Namen herunter. Es ist der schnellste Weg, mehrere Dateien als einen Anhang zu senden.

Bereits komprimierte Dateien wie JPG, MP3, MP4, PDF oder DOCX werden ohne erneute Kompression gespeichert, weil erneutes Pressen nur Zeit kostet und nichts bringt. Doppelte Namen werden umbenannt („datei (2).txt“) und unsichere Pfadteile entfernt. Das ZIP wird in Ihrem Browser mit der Bibliothek fflate gebaut und im Arbeitsspeicher gehalten, Gesamtgrößen von einigen hundert Megabyte sind also in Ordnung, Gigabytes nicht. Es gibt keine Passwortoption, weil die klassische ZIP-Verschlüsselung schwach ist; nutzen Sie für Geheimnisse eine verschlüsselte Notiz oder ein geschütztes PDF.

So benutzt du es

  1. Fügen Sie Dateien hinzu oder wählen Sie einen Ordner.

  2. Benennen Sie das Archiv und wählen Sie die Kompression.

  3. Laden Sie das ZIP herunter.

Häufige Fragen

Kann ich ein Passwort hinzufügen?

Nicht hier. Das alte ZIP-Passwortverfahren ist leicht zu knacken; schützen Sie sensible Dokumente stattdessen mit einem PDF-Passwort oder einer verschlüsselten Notiz.

Warum ist das ZIP kaum kleiner?

Fotos, Videos und die meisten Office-Dateien sind bereits komprimiert, ZIP kann sie daher kaum verkleinern. Text, CSV und Code lassen sich sehr gut komprimieren.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
