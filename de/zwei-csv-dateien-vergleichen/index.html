So funktioniert: Zwei CSV-Dateien vergleichen

Welche Kunden kamen seit letztem Monat dazu? Welche Preise haben sich geändert? Laden Sie zwei Versionen einer Tabelle und sehen Sie die Unterschiede: neue Zeilen grün, entfernte rot, geänderte Zellen gelb mit durchgestrichenem alten Wert. Eine Zusammenfassung zählt jede Art, der vollständige Bericht lässt sich herunterladen.

Zeilen können über eine Schlüsselspalte (ID oder E-Mail-Adresse) zugeordnet oder Position für Position verglichen werden. Mit Schlüssel werden beide Dateien nach diesem Wert indexiert, sodass eine geänderte Reihenfolge keine falschen Unterschiede erzeugt; Zeilen, die nur in einer Datei vorkommen, gelten als hinzugefügt oder entfernt, Zeilen in beiden werden Zelle für Zelle verglichen. Ohne Schlüssel vergleicht das Tool Zeile 1 mit Zeile 1, Zeile 2 mit Zeile 2 und so weiter. Kopfzeilen können als Daten oder als Spaltennamen behandelt werden.

So benutzt du es

  1. Fügen Sie links die ursprüngliche CSV und rechts die geänderte ein oder öffnen Sie sie.

  2. Wählen Sie die Schlüsselspalte, die eine Zeile identifiziert (oder vergleichen Sie Zeile für Zeile).

  3. Prüfen Sie die markierten Unterschiede und laden Sie den Bericht herunter.

Häufige Fragen

Was soll ich als Schlüssel verwenden?

Eine Spalte mit pro Zeile eindeutigen Werten, etwa ID, Artikelnummer oder E-Mail-Adresse. Haben die Zeilen keine ID, vergleichen Sie Zeile für Zeile.

Kommt es mit großen Dateien zurecht?

Es ist für Dateien bis zu einigen hunderttausend Zellen gedacht. Teilen oder filtern Sie riesige Dateien vorher.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
