So funktioniert: Bildwiederholrate & Frame-Drop-Test

Läuft Ihr 144-Hz-Monitor im Browser wirklich mit 144 Hz? Drücken Sie Messen, beobachten Sie den bewegten Balken fünf Sekunden lang und erhalten Sie die gemessene Bildwiederholrate, die nächste Standardrate, die durchschnittliche Frame-Zeit, den Jitter (Standardabweichung der Frame-Zeiten) und die Zahl langsamer Frames, mit Hinweisen, wenn die Animation ungleichmäßig ist.

Die Seite zählt requestAnimationFrame-Callbacks, die Browser einmal pro Bildschirmaktualisierung auslösen, und analysiert die Intervalle dazwischen: Wiederholrate = 1000 ÷ durchschnittliches Intervall in ms. Ein Frame gilt als langsam, wenn er mehr als das 1,5-Fache des erwarteten Intervalls der nächsten gängigen Rate (24–240 Hz) brauchte. Browser können Animationen unter der echten Rate des Monitors begrenzen (Energiesparen, Hintergrund-Tabs, variable Bildwiederholrate), also misst dies, was Webseiten tatsächlich bekommen. Eingabeverzögerung oder Reaktionszeit werden nicht gemessen, dafür braucht man eine Kamera oder ein Hardware-Messgerät.

So benutzt du es

  1. Schließen Sie schwere Tabs und drücken Sie „5 Sekunden messen“.

  2. Beobachten Sie den Balken auf Ruckeln.

  3. Vergleichen Sie die Hz mit Ihren Monitoreinstellungen.

Häufige Fragen

Warum zeigt es 60 Hz auf meinem 144-Hz-Monitor?

Das Betriebssystem ist womöglich auf 60 Hz gestellt, ein Energiesparmodus ist aktiv oder das Browserfenster liegt auf einem anderen Bildschirm.

Was ist ein guter Jitter-Wert?

Unter etwa 1,5 ms auf einem 60-Hz-Display bedeutet eine gleichmäßige Animation.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
