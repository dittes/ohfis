Hex-Farbe mit Transparenz (Deckkraft in Hex)

Deckkraft-Prozente in zweistellige Hex-Alphawerte umrechnen, z. B. 50 % = 80.

So funktioniert: Hex-Farbe mit Transparenz (Deckkraft in Hex)

Fügen Sie einer Hex-Farbe Transparenz hinzu: Geben Sie die Deckkraft in Prozent ein und erhalten Sie das zweistellige Suffix und, mit einer Grundfarbe, den vollständigen 8-stelligen Code (#2557D680). Eine Tabelle listet die üblichen Stufen von 0 bis 100 Prozent.

Der Alphakanal reicht von 0 bis 255, also Hex-Alpha = Rundung(Deckkraft ÷ 100 × 255), zur Basis 16 geschrieben: 50 % → 127,5 → 128 → 80, 80 % → 204 → CC. CSS und Browser verwenden #RRGGBBAA (Alpha zuletzt); Android-Ressourcen nutzen #AARRGGBB (Alpha zuerst), prüfen Sie daher, was Ihre Plattform erwartet.

So benutzt du es

  1. Geben Sie die Deckkraft in Prozent ein.

  2. Geben Sie optional die Grundfarbe ein.

  3. Kopieren Sie das Suffix oder die vollständige Farbe.

Häufige Fragen

Was sind 50 % Deckkraft in Hex?

80 (dezimal 128), also ist #000000 bei halber Deckkraft #00000080.

Nutzt Android dieselbe Reihenfolge?

Nein: Android schreibt Alpha zuerst (#80000000).

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
