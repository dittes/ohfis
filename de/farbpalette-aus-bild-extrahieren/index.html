So funktioniert: Farbpalette aus Bild extrahieren

Bauen Sie ein Farbschema aus einem Logo, Foto oder Produktbild. Das Tool findet die Hauptfarben Ihres Bildes, zeigt jede mit ihrem HEX-Code und ihrem Anteil am Bild und kopiert sie als Liste oder als CSS-Variablen. In Chrome und Edge kann eine Pipette zudem jedes Pixel auf Ihrem Bildschirm aufnehmen.

Das Bild wird auf höchstens 160 Pixel Breite verkleinert, jedes Pixel wird quantisiert und gezählt, und die repräsentativsten Farben werden mit einem gewichteten k-Means-Clustering gefunden, das mit gut getrennten Farben beginnt (Farthest-Point-Initialisierung) und dann jeden Mittelpunkt auf den gewichteten Durchschnitt seiner Gruppe verschiebt. Der Anteil ist der Bruchteil der Pixel, die zu jeder Farbe gehören. Transparente Pixel werden ignoriert. Das Ergebnis hängt von der Zahl der gewünschten Farben ab.

So benutzt du es

  1. Legen Sie ein Bild ab.

  2. Wählen Sie, wie viele Farben Sie möchten.

  3. Klicken Sie auf eine Farbe, um ihren HEX-Code zu kopieren, oder kopieren Sie die ganze Palette.

Häufige Fragen

Wie werden die Farben gewählt?

Durch Clustern ähnlicher Pixel und Mitteln jeder Gruppe, gewichtet nach der Zahl der enthaltenen Pixel.

Kann ich eine Farbe von irgendwo auf dem Bildschirm aufnehmen?

In Chrome und Edge ja, mit der Pipetten-Schaltfläche.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
