So funktioniert: Meme-Generator (Text oben & unten)

Wählen Sie ein Bild, tippen Sie eine obere und eine untere Zeile und erhalten Sie den vertrauten weißen Text mit schwarzer Kontur. Textgröße, Farben und Großbuchstaben lassen sich ändern, lange Zeilen werden automatisch umbrochen, und das fertige Meme lässt sich ohne Wasserzeichen als PNG oder JPEG herunterladen.

Der Text wird mit einer kräftigen Schrift (Impact, falls Ihr System sie hat, sonst Arial Black oder eine fette serifenlose) auf eine Canvas gezeichnet, zuerst umrandet und dann gefüllt, damit er auf jedem Hintergrund lesbar bleibt. Zeilen werden auf 94 % der Bildbreite umbrochen und vom oberen und unteren Rand aus positioniert. Das Bild wird für das Ergebnis auf höchstens 1600 px Breite skaliert. Nichts wird hochgeladen. Stellen Sie sicher, dass Sie das gewählte Bild nutzen und teilen dürfen, und denken Sie an die darauf gezeigten Personen.

So benutzt du es

  1. Wählen Sie das Bild.

  2. Tippen Sie oberen und unteren Text und passen Sie den Stil an.

  3. Laden Sie das Meme herunter.

Häufige Fragen

Gibt es ein Wasserzeichen?

Nein. Bild und Text werden auf Ihrem Gerät verarbeitet, und das Ergebnis ist sauber.

Welche Schrift wird verwendet?

Impact, wenn verfügbar, sonst eine ähnliche fette Schrift. Schriften hängen von Ihrem System ab.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
