So funktioniert: Eisenhower-Matrix mit Haftnotizen (interaktiv)

Die Eisenhower-Matrix sortiert Aufgaben nach zwei Fragen: Ist es dringend, und ist es wichtig? Dringendes und Wichtiges erledigst du zuerst, Wichtiges ohne Dringlichkeit terminierst du, Dringendes ohne Wichtigkeit delegierst du, und den Rest streichst du. Schreibe jede Aufgabe auf eine Haftnotiz, ziehe sie in den passenden Quadranten und färbe sie nach Person oder Projekt.

Deine Matrix wird in diesem Browser gespeichert, nichts wird hochgeladen. Lade sie als PNG herunter, kopiere sie als Markdown für deine Notizen, drucke sie oder speichere sie als Datei. Für eine schnelle reine Textversion nutze die Prioritätenmatrix.

So benutzt du es

  1. Füge in einem Quadranten eine Notiz hinzu und schreibe die Aufgabe.

  2. Ziehe Notizen in den passenden Quadranten oder nutze das Menü an der Notiz.

  3. Drucke die Matrix oder exportiere sie als PNG oder Markdown.

Häufige Fragen

Was gehört in „Terminieren“?

Wichtige Arbeit ohne Termindruck: Planung, Lernen, Gesundheit, Beziehungen. Dieser Quadrant macht langfristig den größten Unterschied.

Wie viele Aufgaben pro Quadrant?

Halte „Zuerst erledigen“ kurz. Läuft das Feld jede Woche über, fehlt meist Planung in „Terminieren“.

Funktioniert es auf dem Handy?

Ja. Die Quadranten werden untereinander gestapelt, und das Menü an jeder Notiz verschiebt sie, weil Ziehen auf kleinen Bildschirmen umständlich ist.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
