So funktioniert: cURL in JavaScript & Python umwandeln

API-Dokumentationen und die Entwicklerwerkzeuge des Browsers liefern curl-Befehle. Fügen Sie einen ein und erhalten Sie äquivalenten JavaScript-fetch-Code und Python-requests-Code mit derselben Methode, denselben Headern, demselben Body, Basic-Auth und Formularfeldern.

Der Befehl wird nach den Quoting-Regeln der Shell in Wörter zerlegt (einfache und doppelte Anführungszeichen, Backslash-Zeilenfortsetzungen, $'…'-Zeichenketten), und die Optionen werden interpretiert: -X, -H, -d / --data-raw / --data-binary, --json, -u, -F, -A, -e, -b, -k, -L und mehr; Optionen, die die Anfrage nicht ändern (-s, -v, -o, --compressed), werden ignoriert. JSON-Bodys werden erkannt und als JSON.stringify(...) oder Python-Dict erzeugt (true/false/null werden zu True/False/None); Basic-Auth wird zu einem Authorization-Header oder dem Argument auth=. Prüfen Sie erzeugten Code vor der Ausführung: Geheimnisse im Befehl landen in Ihrem Code.

So benutzt du es

  1. Fügen Sie einen curl-Befehl ein (im Browser: Netzwerk-Tab → Rechtsklick auf eine Anfrage → Als cURL kopieren).

  2. Lesen Sie das erzeugte JavaScript und Python.

  3. Kopieren Sie den gewünschten Code.

Häufige Fragen

Welche curl-Optionen werden unterstützt?

Methode, Header, Daten, JSON, Authentifizierung, Formulare, User-Agent, Referer, Cookies, Weiterleitungen und unsicherer Modus. Nicht unterstützte Optionen, die die Ausgabe betreffen, werden nach Möglichkeit gemeldet.

Wird mein Befehl irgendwohin gesendet?

Nein. Die Umwandlung läuft in Ihrem Browser, was wichtig ist, weil curl-Befehle oft Tokens enthalten.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
