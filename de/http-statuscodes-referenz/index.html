So funktioniert: HTTP-Statuscodes Referenz

Suchen Sie nach Nummer oder Stichwort, um zu sehen, was ein Statuscode bedeutet und was man dagegen tun kann. Alle in der Praxis wichtigen Codes von 1xx bis 5xx aus dem IANA-Register sind nach Klasse gruppiert aufgeführt, jeweils mit kurzer Erklärung und einem Hinweis zur Behebung.

Die erste Ziffer gibt die Klasse an: 1xx informativ, 2xx Erfolg, 3xx Umleitung, 4xx Client-Fehler und 5xx Server-Fehler. Für jeden Code erklärt der Eintrag, was der Server sagt, sowie die häufigste Ursache und Lösung: 502 bedeutet etwa, dass ein Proxy eine ungültige Antwort der dahinterliegenden Anwendung erhielt, 504, dass die Anwendung zu langsam war, und 429, dass Sie ratenbegrenzt sind und auf Retry-After warten sollten. Die Suche umfasst Codes, Namen und Beschreibungen.

So benutzt du es

  1. Geben Sie einen Code (404) oder ein Stichwort (redirect, timeout) ein.

  2. Filtern Sie optional nach Klasse.

  3. Lesen Sie die Erklärung und was Sie versuchen können.

Häufige Fragen

Was ist der Unterschied zwischen 401 und 403?

401 bedeutet, dass Sie nicht authentifiziert sind (keine oder ungültige Zugangsdaten). 403 bedeutet, dass der Server weiß, wer Sie sind, Sie aber nicht berechtigt sind.

301 oder 302 für Weiterleitungen?

301 für dauerhafte Umzüge (Suchmaschinen übertragen das Ranking), 302 oder 307 für vorübergehende.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
