So funktioniert: Bildschirm-Farbkarte (Weißabgleich & Helligkeit)

Zeigen Sie eine neutrale Graukarte (18 %), Tageslichtweiß (6500 K), warm (3200 K) oder kühl (7500 K), eine beliebige Farbe oder eine Graustufenskala mit 256 Stufen und gehen Sie in den Vollbildmodus. Halten Sie sie vor eine Webcam, um den Weißabgleich einzustellen, nutzen Sie sie als weiches Licht für Videoanrufe oder prüfen Sie einen Bildschirm auf Farbstich, ungleichmäßige Helligkeit und hängende Pixel.

Die Farbtemperaturen sind Näherungen der üblichen sRGB-Werte für die benannten Weißpunkte; echte Kalibrierung braucht ein Messgerät (Colorimeter), weil jeder Bildschirm anders ist. Die Karte ist ein einfaches Element mit CSS-Farbe, und der Vollbildmodus nutzt die Fullscreen API, sodass nichts hochgeladen oder aufgenommen wird. Für den Weißabgleich richten Sie die Kamera so auf die Karte, dass sie das Bild füllt, und nutzen die Funktion „Weißabgleich setzen“ oder „Klicken für Weißabgleich“ Ihrer Kamera-App.

So benutzt du es

  1. Wählen Sie eine Voreinstellung oder eine Farbe.

  2. Drücken Sie Vollbild.

  3. Halten Sie sie vor die Kamera oder prüfen Sie den Bildschirm.

Häufige Fragen

Welche Karte soll ich für den Weißabgleich nehmen?

Die neutrale Graukarte ist die beste Referenz; eine weiße Karte funktioniert, wenn sie nicht überbelichtet ist.

Kann das meinen Monitor kalibrieren?

Nein. Es hilft, Probleme zu erkennen; Kalibrierung braucht ein Hardware-Colorimeter.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
