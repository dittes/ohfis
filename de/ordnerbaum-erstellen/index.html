Ordnerbaum erstellen (Verzeichnisstruktur als Text)

Einen Ordner oder eine Pfadliste in einen Textbaum für die Dokumentation umwandeln.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Ordnerbaum erstellen (Verzeichnisstruktur als Text)

Wählen oder ziehen Sie einen Ordner hinein oder fügen Sie eine Pfadliste ein und erhalten Sie die Struktur als Textbaum mit ├──- und └──-Zeilen, bereit für eine README, ein Ticket oder eine Dokumentation. Optionen blenden Ordner wie node_modules und .git aus, begrenzen die Tiefe, zeigen nur Ordner, zeigen Dateigrößen und sortieren nach Name oder Größe.

Es werden nur Namen und Größen der Dateien gelesen, nie ihr Inhalt, und nichts verlässt Ihren Rechner. Eingefügte Listen funktionieren mit Schrägstrichen und Backslashes, und Pfade, die auf einen Schrägstrich enden, gelten als Ordner. Leere Ordner erscheinen, wenn Ihr Browser sie meldet; bei sehr großen Ordnern (Zehntausende Dateien) kann der Browser einen Moment brauchen.

So benutzt du es

  1. Ziehen oder wählen Sie einen Ordner oder fügen Sie Pfade ein.

  2. Legen Sie Ignorierliste, Tiefe und Optionen fest.

  3. Kopieren Sie den Baum oder laden Sie ihn herunter.

Häufige Fragen

Wird der Inhalt meiner Dateien gelesen?

Nein. Nur Namen und Größen.

Wie zeige ich nur die oberste Ebene?

Stellen Sie „Maximale Tiefe“ auf 1.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
