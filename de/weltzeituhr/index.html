Weltzeituhr

Ein eigenes Raster mit Live-Uhren für Büros und Kontakte weltweit.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Weltzeituhr

Behalten Sie die aktuelle Uhrzeit Ihrer Büros, Kunden und Familie in einer Ansicht im Blick. Fügen Sie eine beliebige Stadt oder IANA-Zeitzone hinzu, entfernen Sie nicht benötigte und wechseln Sie zwischen 12- und 24-Stunden-Anzeige. Ihre Liste wird in Ihrem Browser gemerkt.

Jede Karte zeigt die lokale Live-Zeit, das Datum und den Versatz zu UTC, berechnet mit der Zeitzonendatenbank des Browsers, sodass Sommerzeitwechsel automatisch angewendet werden, auch bei Halbstunden- und 45-Minuten-Zonen wie Indien und Nepal. Die Liste wird nur im localStorage Ihres Geräts gespeichert, und nichts wird an einen Server gesendet.

So benutzt du es

  1. Wählen Sie Städte oder Zeitzonen zum Hinzufügen.

  2. Entfernen Sie die nicht benötigten.

  3. Lassen Sie die Seite für eine Live-Ansicht offen; Ihre Liste wird gespeichert.

Häufige Fragen

Ist die Zeit genau?

Sie nutzt die Uhr Ihres Geräts. Geht die Uhr Ihres Computers falsch, sind alle angezeigten Zeiten um denselben Betrag falsch.

Wo wird meine Liste gespeichert?

Nur in Ihrem Browser (localStorage). Das Löschen von Websitedaten entfernt sie.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
