So funktioniert: E-Mail-Adressen extrahieren

Fügen Sie einen Postfach-Export, den Quelltext einer Webseite, eine CC-Zeile oder beliebigen unordentlichen Text ein und erhalten Sie eine saubere alphabetische Liste der darin enthaltenen E-Mail-Adressen. Duplikate werden entfernt, Adressen kleingeschrieben, und Sie können sie nach Domain gruppieren, um zu sehen, welche Firmen am häufigsten vorkommen.

Ein Muster aus lokalem Teil, @-Zeichen und Domain mit Top-Level-Domain findet die Adressen; umgebende Satzzeichen wie spitze Klammern, Kommas und abschließende Punkte werden ignoriert. Der Abgleich ignoriert Groß-/Kleinschreibung, und Adressen werden vor dem Entfernen von Duplikaten in Kleinbuchstaben normalisiert. Nichts wird irgendwohin gesendet, was wichtig ist, wenn die Liste personenbezogene Daten enthält.

So benutzt du es

  1. Fügen Sie Ihren Text ein.

  2. Haken Sie optional „Nach Domain gruppieren“ an.

  3. Kopieren Sie die Liste oder laden Sie sie als Textdatei herunter.

Häufige Fragen

Werden Adressen an einen Server gesendet?

Nein. Die Extraktion läuft in Ihrem Browser. Kontaktlisten verlassen Ihr Gerät nie.

Prüft es, ob eine Adresse wirklich existiert?

Nein. Es findet Text, der wie eine E-Mail-Adresse aussieht. Es kann nicht feststellen, ob ein Postfach existiert.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
