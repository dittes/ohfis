Präfix oder Suffix zu Zeilen hinzufügen

Text, Nummern oder Tags vor oder nach jeder Zeile in einem Schritt hinzufügen.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Präfix oder Suffix zu Zeilen hinzufügen

Setzen Sie jede Zeile in Anführungszeichen, fügen Sie einen Aufzählungspunkt hinzu, hängen Sie ein Semikolon an oder nummerieren Sie eine Liste: Tippen Sie, was vor und nach jeder Zeile stehen soll, und es wird auf Tausende Zeilen gleichzeitig angewendet. Nutzen Sie {n} irgendwo im Präfix oder Suffix, um einen Zähler einzufügen, der bei jeder Zahl beginnen und mit Nullen aufgefüllt werden kann.

Der Text wird in Zeilen zerlegt, und Präfix und Suffix werden jeder hinzugefügt. Leere Zeilen werden standardmäßig übersprungen, damit leere Trenner leer bleiben. Der Zähler steigt pro nichtleerer Zeile um eins und wird auf die gewählte Stellenzahl mit führenden Nullen aufgefüllt (zum Beispiel 007).

So benutzt du es

  1. Fügen Sie Ihre Zeilen ein.

  2. Geben Sie den Text davor und danach ein, mit {n} für einen Zähler, falls nötig.

  3. Kopieren Sie das Ergebnis.

Häufige Fragen

Wie nummeriere ich Zeilen?

Haken Sie „Zähler einfügen“ an und setzen Sie {n} ins Präfix, zum Beispiel „{n}. “. Legen Sie Startzahl und Stellenzahl fest.

Kann ich nur am Ende Text anhängen?

Ja. Lassen Sie das Präfix leer und füllen Sie nur das Suffix.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.

Das könnte auch helfen

Liste in kommagetrennten Text umwandeln Zeilen in Komma-, Tab- oder Anführungszeichen-Listen, Arrays und SQL-IN-Listen verwandeln. Zeilen alphabetisch sortieren Listen A–Z, Z–A, nach Länge oder natürlich (v2 vor v10) sortieren. Doppelte Zeilen entfernen Doppelte Zeilen löschen und sehen, wie oft jede vorkam. Zeilen filtern (Text-Grep) Zeilen behalten oder entfernen, die einen Suchbegriff enthalten oder damit beginnen.
