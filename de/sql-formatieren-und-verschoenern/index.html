So funktioniert: SQL formatieren und verschönern

Fügen Sie eine lange einzeilige Abfrage ein und erhalten Sie sie formatiert, mit jeder Klausel in eigener Zeile, eingerückten Joins und Bedingungen und Schlüsselwörtern in Großbuchstaben. Wählen Sie den Dialekt (Standard-SQL, PostgreSQL, MySQL, MariaDB, SQLite, SQL Server, Oracle, BigQuery, Snowflake), die Schreibweise der Schlüsselwörter und die Einrückung.

Der Formatierer ist die Open-Source-Bibliothek sql-formatter, die in Ihrem Browser läuft; Ihre Abfragen werden nirgendwohin gesendet, was wichtig ist, wenn sie Tabellennamen oder Werte aus einem echten System enthalten. Er formatiert nur; er prüft nicht, ob die Abfrage laufen würde, und ungewöhnliche herstellerspezifische Syntax kann anders umbrochen werden, als Sie es tun würden.

So benutzt du es

  1. Fügen Sie das SQL ein.

  2. Wählen Sie Dialekt, Schlüsselwort-Schreibweise und Einrückung.

  3. Kopieren Sie die formatierte Abfrage.

Häufige Fragen

Prüft es mein SQL?

Nein. Es formatiert nur. Ein Syntaxfehler kann als Formatierungsfehler auftauchen, aber eine gültig aussehende Abfrage kann in Ihrer Datenbank trotzdem scheitern.

Welchen Dialekt soll ich wählen?

Den Ihrer Datenbank. Standard-SQL genügt für einfache Abfragen; herstellerspezifische Funktionen formatieren am besten mit dem passenden Dialekt.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
