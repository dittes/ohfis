So funktioniert: PDF-Markierungen & Kommentare extrahieren

Haben Sie eine Arbeit oder einen Vertrag mit Markierungen und Haftnotizen gelesen, legen Sie das PDF hier ab und erhalten Sie eine Liste nach Seiten: Art der Anmerkung, Autor, markierter Text und Kommentar. Kopieren Sie sie als Markdown-Liste für Ihre Notizen oder laden Sie CSV für eine Tabelle herunter.

Das Tool liest die Anmerkungsobjekte jeder Seite mit pdf.js: Markierungen, Unterstreichungen, Durchstreichungen, Wellenlinien, Haftnotizen und Textfelder. Bei Markup-Anmerkungen nimmt es die Vierecke, die den Bereich markieren, und sammelt die Textelemente der Seite, deren Mitte darin liegt, in Lesereihenfolge, sodass die markierten Wörter als Text herauskommen. Dafür braucht es eine Textebene; gescannte PDFs ohne OCR liefern Markierungen ohne Text. Zeichnungen, reduzierte Anmerkungen (in die Seite eingebrannt) und Anmerkungen, deren App den Text anderswo speichert, werden nicht gefunden. Die Datei wird lokal verarbeitet.

So benutzt du es

  1. Legen Sie das kommentierte PDF ab.

  2. Wählen Sie, welche Arten von Anmerkungen angezeigt werden.

  3. Kopieren Sie das Markdown oder laden Sie die CSV herunter.

Häufige Fragen

Warum ist der markierte Text leer?

Das PDF hat keine Textebene (ein Scan) oder die Markierung deckt nur ein Bild ab. Führen Sie zuerst OCR aus.

Findet es Anmerkungen aus einem Browser oder der Vorschau?

Ja, wenn die App sie als normale PDF-Anmerkungen gespeichert hat. Reduzierte sind Teil der Seite und nicht lesbar.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
