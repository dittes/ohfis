Urkunden-Generator (druckbare PDF-Zertifikate)

Zertifikate für viele Namen gleichzeitig erstellen und als ein PDF herunterladen.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Urkunden-Generator (druckbare PDF-Zertifikate)

Wählen Sie Titel und Wortlaut, eine Farbe und das Papier, fügen Sie eine Namensliste ein (einen pro Zeile) und erhalten Sie für jeden ein Querformat-Zertifikat in einem einzigen PDF, druckfertig für einen Kurs, ein Team, eine Klasse oder einen Wettbewerb. Das erste Zertifikat lässt sich auch als PNG speichern.

Jedes Zertifikat wird auf einer Canvas mit 150 dpi gezeichnet, mit Doppelrahmen, zentriertem Titel, dem Namen des Empfängers in großer Serifenschrift, die für lange Namen schrumpft, dem Text, einem Datum und einer Unterschriftslinie. Die Seiten werden im exakten Papierformat (A4 oder US Letter quer) in ein PDF eingebettet. Alles wird in Ihrem Browser gerendert, die Namensliste wird also nie hochgeladen. Pro Durchlauf werden bis zu 200 Zertifikate erstellt.

So benutzt du es

  1. Geben Sie Titel, Text, Datum und Unterzeichner ein.

  2. Fügen Sie die Namen ein, einen pro Zeile.

  3. Laden Sie das PDF mit einem Zertifikat pro Name herunter.

Häufige Fragen

Kann ich ein Logo hinzufügen?

In dieser Version nicht. Drucken Sie auf Briefpapier oder fügen Sie das Logo später mit dem PDF-Editor hinzu.

Wie viele Namen kann ich eingeben?

Bis zu 200 pro Durchlauf.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
