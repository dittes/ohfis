Als reinen Text einfügen (Formatierung entfernen)

Ein Zwischenfeld, das Schriften, Farben und Links entfernt, bevor du woanders einfügst.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Als reinen Text einfügen (Formatierung entfernen)

Kopieren Sie Text von einer Webseite oder aus Word, fügen Sie ihn in das Feld ein und kopieren Sie ihn als reinen Text wieder heraus, ohne Schriften, Farben, Links oder versteckte Stile, bereit zum Einfügen in ein Formular, CMS oder Dokument, ohne dessen Layout zu stören. Optionale Bereinigungen kürzen die Enden, fassen Leerzeilen zusammen und ersetzen typografische Anführungszeichen und Sonderleerzeichen.

Beim Einfügen liest das Tool nur die text/plain-Version der Zwischenablage und fügt diese ein; die HTML-Version mit der Formatierung wird verworfen. Alles bleibt in Ihrem Browser. Die meisten Editoren bieten Strg+Umschalt+V (⌘⇧V) für denselben Effekt; diese Seite ist ein bequemer Ersatz und bereinigt den Text zusätzlich.

So benutzt du es

  1. Fügen Sie Ihren formatierten Text in das Feld ein.

  2. Haken Sie die gewünschten Bereinigungen an.

  3. Kopieren Sie den reinen Text.

Häufige Fragen

Wie lautet das Tastenkürzel zum Einfügen ohne Formatierung?

Strg+Umschalt+V unter Windows und Linux, ⌘⇧V auf dem Mac, in den meisten Browsern und Editoren.

Werden Bilder übernommen?

Nein. Nur Text bleibt erhalten.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
