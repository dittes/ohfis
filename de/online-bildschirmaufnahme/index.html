Online-Bildschirmaufnahme

Einen Bildschirm, ein Fenster oder Tab aufnehmen, mit optionalem Ton, und als Video speichern.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Online-Bildschirmaufnahme

Nehmen Sie eine Demo, einen Fehler oder ein Tutorial direkt im Browser auf. Wählen Sie im browsereigenen Dialog einen ganzen Bildschirm, ein Fenster oder einen Browser-Tab, fügen Sie optional Ihr Mikrofon und den Ton des Tabs hinzu und laden Sie die Aufnahme als Videodatei herunter, wenn Sie Stopp drücken.

Das Tool nutzt die Screen Capture API (getDisplayMedia) und MediaRecorder. Das Video wird vom Browser kodiert (WebM mit VP9 oder VP8 und Opus-Audio, MP4, wo WebM nicht unterstützt wird) und im Speicher gesammelt; eine lange Aufnahme eines großen Bildschirms braucht daher viel RAM: Nehmen Sie in Teilen auf, wenn sie länger als etwa eine halbe Stunde läuft. Nichts wird hochgeladen. Systemton lässt sich nur aufnehmen, wenn ein Tab geteilt wird oder, in manchen Browsern unter Windows und ChromeOS, der gesamte Bildschirm; macOS bietet in den meisten Browsern keinen Systemton beim Bildschirmteilen.

So benutzt du es

  1. Drücken Sie Aufnahme starten und wählen Sie, was geteilt wird.

  2. Beenden Sie mit der Schaltfläche oder der Freigabeleiste des Browsers.

  3. Spielen Sie es ab und laden Sie das Video herunter.

Häufige Fragen

Kann ich Systemton aufnehmen?

Nur beim Teilen eines Browser-Tabs (und auf manchen Systemen des ganzen Bildschirms). Andernfalls fügen Sie Ihr Mikrofon hinzu.

Warum ist die Datei WebM?

Es ist das Format, das Browser direkt erzeugen können. Die meisten Player und Editoren öffnen es; wandeln Sie bei Bedarf mit einem Desktop-Tool in MP4 um.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
