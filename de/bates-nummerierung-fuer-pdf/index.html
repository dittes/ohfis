So funktioniert: Bates-Nummerierung für PDF

Bates-Nummern geben jeder Seite eines Rechts-, Prüf- oder Beweisdokumentensatzes eine eindeutige, geordnete Kennung. Geben Sie ein Präfix, die Startnummer, die Stellenzahl und ein Suffix ein, wählen Sie eine Seitenecke und erhalten Sie das gestempelte PDF.

Jede Seite erhält das Label Präfix + aufgefüllte Nummer + Suffix (zum Beispiel ACME-000001), gezeichnet als echter Text mit eingebetteter Schrift, die Akzente und Kyrillisch unterstützt, optional auf weißer Box für bessere Lesbarkeit auf unruhigen Seiten. Positionen werden in Millimetern vom Seitenrand gemessen und funktionieren für Seiten jeder Größe und Drehung der Seitenbox. Um eine Reihe in einer anderen Datei fortzusetzen, geben Sie die nächste Nummer als Start ein. Der Stempel ist dauerhafter Text auf der Seite; behalten Sie das Original, falls Sie eine ungestempelte Version brauchen.

So benutzt du es

  1. Wählen Sie das PDF.

  2. Geben Sie Präfix, Startnummer, Stellenzahl und Position ein.

  3. Laden Sie das nummerierte PDF herunter.

Häufige Fragen

Kann ich die Nummerierung in einer zweiten Datei fortsetzen?

Ja. Setzen Sie die Startnummer auf die letzte Nummer plus eins.

Kann ich nur einige Seiten nummerieren?

In dieser Version nicht. Nutzen Sie zuerst das Werkzeug Teilen oder Extrahieren.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
