So funktioniert: CSV-Trennzeichen ändern

Excel in Deutschland, Frankreich oder Polen speichert CSV-Dateien mit Semikolons, US-Programme erwarten Kommas, Datenbanken bevorzugen Tabulatoren. Öffnet sich eine Datei als eine einzige lange Spalte, stimmt das Trennzeichen nicht. Dieses Tool erkennt das Trennzeichen Ihrer Datei und schreibt sie mit dem gewünschten neu – von CSV zu TSV und zurück, ohne Zellen zu zerstören, die Kommas, Anführungszeichen oder Zeilenumbrüche enthalten.

Die Erkennung prüft die ersten Zeilen der Datei und zählt, wie oft jeder Kandidat (Komma, Semikolon, Tabulator, senkrechter Strich) außerhalb von Anführungszeichen vorkommt. Gewinnt das Zeichen, das in den meisten Zeilen gleich oft auftritt. Danach wird die Datei mit einem vollständigen RFC-4180-Leser eingelesen (Felder in Anführungszeichen, doppelte Anführungszeichen, Zeilenumbrüche in Zellen) und mit dem neuen Trennzeichen wieder geschrieben; nur Zellen, die es brauchen, werden in Anführungszeichen gesetzt. Optionen setzen überall Anführungszeichen, Windows-Zeilenenden oder eine UTF-8-BOM, damit Excel Umlaute korrekt anzeigt.

So benutzt du es

  1. Fügen Sie Ihre Daten ein oder öffnen Sie eine Datei. Das erkannte Trennzeichen wird angezeigt.

  2. Wählen Sie unter „Ausgabeformat“ das gewünschte Trennzeichen.

  3. Kopieren Sie das Ergebnis oder laden Sie es als neue Datei herunter.

Häufige Fragen

Warum öffnet sich meine CSV-Datei in Excel in einer Spalte?

Excel erwartet das Listentrennzeichen Ihrer Regionaleinstellungen (in vielen europäischen Ländern das Semikolon). Wandeln Sie die Datei in dieses Trennzeichen um oder nutzen Sie Daten → Aus Text/CSV und wählen Sie das Trennzeichen.

Werden Kommas in Zellen zerstört?

Nein. Zellen, die das Trennzeichen enthalten, werden in Anführungszeichen gesetzt – genau wie es der CSV-Standard verlangt.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
