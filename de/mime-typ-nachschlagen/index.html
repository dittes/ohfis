MIME-Typ nachschlagen (Dateiendung zu Content-Type)

Den richtigen Content-Type zu einer Dateiendung finden oder die Endung zu einem MIME-Typ.

So funktioniert: MIME-Typ nachschlagen (Dateiendung zu Content-Type)

Welchen Content-Type soll ein Server für eine .docx-, .webp- oder .wasm-Datei senden? Suchen Sie nach Endung, Dateiname oder MIME-Typ und erhalten Sie den registrierten Wert, auch die langen Namen der Office-Formate.

Ein MIME-Typ (Medientyp) hat die Form Typ/Untertyp, etwa image/png, und sagt Browsern, wie sie eine Antwort behandeln. Texttypen ergänzen normalerweise einen Zeichensatz, z. B. text/html; charset=utf-8. Ist der Typ falsch, laden Browser eine Datei womöglich herunter, statt sie anzuzeigen, verweigern die Ausführung eines Skripts (Modul-Skripte brauchen einen JavaScript-Typ) oder lehnen eine Schrift ab. Für unbekannte Binärdaten ist application/octet-stream der sichere Standard. Die Liste deckt gängige Web-, Dokument-, Bild-, Audio-, Video-, Archiv- und Schriftformate ab.

So benutzt du es

  1. Geben Sie eine Endung wie .docx oder einen MIME-Typ wie image/png ein.

  2. Kopieren Sie den passenden Content-Type.

  3. Konfigurieren Sie Ihren Server oder Upload entsprechend.

Häufige Fragen

Was ist der MIME-Typ einer .docx-Datei?

application/vnd.openxmlformats-officedocument.wordprocessingml.document.

Was nehme ich, wenn ich den Typ nicht kenne?

application/octet-stream; er sagt dem Browser, dass es allgemeine Binärdaten sind.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
