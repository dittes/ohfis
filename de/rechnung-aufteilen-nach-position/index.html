So funktioniert: Rechnung aufteilen nach Position

Fügen Sie die Personen hinzu, listen Sie jeden Posten mit Preis auf und haken Sie ab, wer ihn geteilt hat (niemand abgehakt heißt alle). Steuer und Trinkgeld werden im Verhältnis zu dem, was jeder bestellt hat, aufgeschlagen, und Sie erhalten einen klaren Betrag pro Person zum Kopieren in den Gruppenchat.

Jeder Posten wird gleichmäßig auf die Personen verteilt, die ihn geteilt haben. Das Trinkgeld ist ein Prozentsatz der Posten; die Steuer ist ein fester Betrag aus dem Beleg. Beide werden im Verhältnis zum Anteil jeder Person an der Zwischensumme verteilt. Anteile werden auf den Cent gerundet, und übrige Cent werden verteilt, sodass die Summe aller Anteile genau die Rechnung ergibt.

So benutzt du es

  1. Geben Sie die Namen der Personen ein.

  2. Fügen Sie die Posten hinzu und haken Sie ab, wer jeden geteilt hat.

  3. Geben Sie Steuer und Trinkgeld ein und kopieren Sie die Beträge.

Häufige Fragen

Wie werden geteilte Gerichte behandelt?

Haken Sie jede Person ab, die den Posten geteilt hat; sein Preis wird gleichmäßig auf sie verteilt.

Warum wird die Steuer anteilig verteilt?

Weil, wer mehr bestellt hat, auch mehr Steuer verursacht hat; Sie können die Steuer trotzdem als einen Betrag eingeben.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
