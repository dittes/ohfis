So funktioniert: Schrift-Konverter (TTF/OTF in WOFF und zurück)

Ziehen Sie eine TTF- oder OTF-Schrift hinein und erhalten Sie eine WOFF-Datei für Ihre Website, meist etwa ein Drittel kleiner; ziehen Sie eine WOFF hinein und erhalten Sie TTF oder OTF zurück. Das Tool zeigt Schriftfamilie, Stil und Zahl der Glyphen, zeigt eine Vorschau Ihres Textes in der Schrift und schreibt das passende @font-face-CSS zum Kopieren.

WOFF 1.0 sind dieselben Schriftdaten mit zlib-komprimierten Tabellen, die Umwandlung ändert also weder Umrisse noch Metriken: Die Tabellen werden Byte für Byte kopiert und nur ein- oder ausgepackt. Deshalb ist die Umwandlung exakt und sofort fertig. WOFF2, das kleinste Web-Schriftformat, braucht Brotli-Kompression und schriftspezifische Transformationen, die dieses Tool nicht kann; es sagt Ihnen Bescheid, wenn Sie eine hineinziehen. Schriftsammlungen (.ttc) werden ebenfalls nicht unterstützt. Prüfen Sie die Lizenz der Schrift, bevor Sie sie auf einer Website nutzen: Nicht jede Desktop-Schrift darf eingebettet werden.

So benutzt du es

  1. Ziehen Sie die Schriftdatei hinein.

  2. Prüfen Sie Vorschau und Schriftdetails.

  3. Laden Sie die umgewandelte Datei herunter und kopieren Sie das CSS.

Häufige Fragen

Warum nicht WOFF2?

WOFF2 braucht Brotli-Kompression, wofür eine große zusätzliche Bibliothek nötig wäre. WOFF funktioniert in jedem aktuellen Browser; für das letzte Stück Größe nutzen Sie ein Build-Tool auf Ihrem Server.

Ändert die Umwandlung das Aussehen der Schrift?

Nein. Die Glyphendaten werden unverändert kopiert; nur die Verpackung unterscheidet sich.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
