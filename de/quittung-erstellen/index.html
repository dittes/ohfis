So funktioniert: Quittung erstellen (PDF)

Erstellen Sie eine Quittung als PDF mit Betrag, Mehrwertsteuer-Aufschlüsselung, Verwendungszweck, Zahlungsart, Ort und Datum. Der Bruttobetrag wird anhand des Steuersatzes in Netto und Steuer zerlegt.

Die Datei entsteht komplett lokal in Ihrem Browser. Bitte prüfen Sie bei Bedarf die Anforderungen Ihres Landes an Belege.

So benutzt du es

  1. Geben Sie Betrag, Steuersatz und Verwendungszweck ein.

  2. Ergänzen Sie Zahlungsart, Ort, Datum sowie Aussteller und Zahler.

  3. Klicken Sie auf PDF erstellen und laden Sie die Quittung herunter.

Häufige Fragen

Ist die Quittung rechtlich ausreichend?

Das hängt vom Land und vom Anlass ab. Das Werkzeug erstellt ein übliches Layout, ersetzt aber keine Rechtsberatung.

Kann ich einen Steuersatz von 0 % wählen?

Ja, dann wird keine Steuer ausgewiesen.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
