Verschlüsselte Notiz als Link

Eine kurze Nachricht im Browser verschlüsseln und als Link plus separaten Schlüssel teilen.

So funktioniert: Verschlüsselte Notiz als Link

Teilen Sie ein Passwort oder eine private Nachricht, ohne sie im Chatverlauf lesbar zu hinterlassen. Schreiben Sie die Notiz, und Sie erhalten einen Link und getrennt davon einen Schlüssel (oder nutzen Sie Ihr eigenes Passwort). Senden Sie beide über verschiedene Kanäle: Wer beides hat, kann die Notiz lesen.

Die Nachricht wird in Ihrem Browser mit AES-256-GCM (Web Crypto) verschlüsselt. Im Modus „Zufallsschlüssel“ wird ein frischer 256-Bit-Schlüssel erzeugt und separat angezeigt; im Modus „Passwort“ wird der Schlüssel aus Ihrem Passwort mit PBKDF2-SHA-256 (210.000 Iterationen) und einem zufälligen Salt abgeleitet. Die verschlüsselte Notiz steht im Teil des Links nach dem #-Zeichen, den Browser nie an Server senden, und diese Website speichert nichts. Das Authentifizierungs-Tag macht jede Änderung der Notiz erkennbar. Ehrliche Grenzen: Ohne Server gibt es keine Möglichkeit, den Link selbstzerstören zu lassen oder zu begrenzen, wie oft er geöffnet wird, und die Linklänge begrenzt die Nachrichtenlänge.

So benutzt du es

  1. Schreiben Sie Ihre Nachricht und wählen Sie einen Zufallsschlüssel oder ein Passwort.

  2. Senden Sie den Link über einen Kanal und den Schlüssel oder das Passwort über einen anderen.

  3. Der Empfänger öffnet den Link, gibt den Schlüssel ein und liest die Notiz.

Häufige Fragen

Kann die Notiz nach dem Lesen gelöscht werden?

Nein. Es gibt keinen Server, der sie löschen könnte. Jeder mit Link und Schlüssel kann sie jederzeit öffnen.

Ist es wirklich privat?

Der Text verlässt Ihren Browser nie unverschlüsselt und wird von uns nicht gespeichert. Seine Sicherheit hängt davon ab, dass Link und Schlüssel getrennt gesendet werden, und von der Stärke eines Passworts.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
