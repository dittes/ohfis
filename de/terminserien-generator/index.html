Terminserien-Generator

Die Termine einer wiederkehrenden Veranstaltung auflisten, z. B. jeden zweiten Dienstag.

Tool wird geladen…

  • Kein Upload
  • Kostenlos
  • Kein Konto
  • Einmal geladen, auch offline nutzbar

So funktioniert: Terminserien-Generator

Planen Sie ein Projekt, eine Schulungsreihe oder einen Zahlungsplan: Wählen Sie das erste Datum und die Wiederholung (alle N Tage, Wochen, Monate oder Jahre, an bestimmten Wochentagen oder am ersten, zweiten oder letzten Wochentag jedes Monats) und erhalten Sie die Liste der Daten mit Wochentagen, bereit zum Kopieren oder als CSV-Download.

Daten werden in UTC-Kalenderarithmetik erzeugt, sodass die Sommerzeit sie nie verschiebt. Monatliche Wiederholungen werden am Ende kurzer Monate gekappt (auf den 31. Januar folgt der 29. Februar), „n-ter Wochentag“-Regeln finden den richtigen Dienstag oder Freitag jedes Monats, und eine Option verschiebt Daten, die auf Wochenenden oder Feiertage fallen, auf den nächsten Arbeitstag.

So benutzt du es

  1. Wählen Sie das erste Datum und das Wiederholungsmuster.

  2. Legen Sie fest, wie viele Daten Sie brauchen und wie Wochenenden oder Feiertage behandelt werden.

  3. Kopieren Sie die Liste oder laden Sie sie als CSV herunter.

Häufige Fragen

Wie erhalte ich den zweiten Dienstag jedes Monats?

Wählen Sie „jeden 1. Monat“, „zweiter Wochentag des Monats“ und ein erstes Datum, das ein Dienstag ist.

Was passiert am 31.?

Monate ohne 31. nutzen ihren letzten Tag.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
