So funktioniert: Favicon-HTML-Tags erzeugen

Wählen Sie, welche Icon-Dateien Sie haben, und erhalten Sie die passenden <link>-Tags in der von Browsern bevorzugten Reihenfolge sowie ein fertiges Web-App-Manifest. Kombinieren Sie es mit dem Favicon- & App-Icon-Generator, um die Bilddateien selbst zu erstellen.

Moderne Setups brauchen wenig: ein SVG-Icon (skaliert, unterstützt den Dunkelmodus), eine 32-px-.ico- oder PNG-Rückfalldatei, ein 180-px-apple-touch-icon und ein Manifest mit Icons von 192 und 512 px für Android und installierbare Web-Apps. Tags und Manifest verwenden den von Ihnen eingegebenen Ordner, sodass die Pfade von jeder Seite aus funktionieren.

So benutzt du es

  1. Geben Sie den Ordner mit Ihren Icons ein.

  2. Wählen Sie die vorhandenen Icons und legen Sie die Themenfarbe fest.

  3. Kopieren Sie die Tags in <head> und speichern Sie das Manifest.

Häufige Fragen

Welche Favicon-Größen brauche ich?

Ein SVG oder ein 32×32-PNG/ICO für Browser, 180×180 für Apple-Geräte und 192×192 sowie 512×512 für Android.

Wo lege ich favicon.ico ab?

Im Stammordner Ihrer Website; Browser fragen dort standardmäßig danach.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
