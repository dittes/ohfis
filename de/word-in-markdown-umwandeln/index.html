Word (DOCX) in Markdown umwandeln

Die Struktur eines Word-Dokuments lokal als sauberes Markdown extrahieren.

So funktioniert: Word (DOCX) in Markdown umwandeln

Legen Sie eine .docx-Datei ab und erhalten Sie Markdown mit Überschriften (#), Fett, Kursiv, Links, Aufzählungen und nummerierten Listen (auch verschachtelt), Zitaten, Code und Tabellen, bereit für GitHub, ein Wiki, eine statische Website oder einen KI-Prompt. Kopieren Sie den Text oder laden Sie ihn als .md-Datei herunter.

Eine .docx ist ein ZIP aus XML-Dateien. Das Tool entpackt sie im Browser, liest Dokument- und Nummerierungsteile und geht die Absätze durch: Überschriftenformate werden zu #-Ebenen, Listenabsätze nutzen die Nummerierungsdefinition, um zwischen Aufzählung und Nummerierung zu entscheiden, Zeicheneigenschaften werden zu ** und *, Hyperlinks werden über die Beziehungsdatei aufgelöst und Tabellen werden zu Pipe-Tabellen. Bilder, Kommentare, Änderungsnachverfolgung, Fußnoten und Textfelder werden nicht umgewandelt, und ungewöhnliche eigene Formate brauchen eventuell Nacharbeit. Alte .doc-Dateien müssen zuerst als .docx gespeichert werden.

So benutzt du es

  1. Legen Sie eine .docx-Datei ab.

  2. Prüfen Sie das Markdown.

  3. Kopieren Sie es oder laden Sie die .md-Datei herunter.

Häufige Fragen

Sind Bilder enthalten?

Nein. Die Zahl übersprungener Bilder wird angezeigt. Exportieren Sie Bilder separat aus Word.

Kommt es mit alten .doc-Dateien zurecht?

Nein. Speichern Sie sie zuerst in Word oder LibreOffice als .docx.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
