So funktioniert: CSV-Spaltenüberschriften bereinigen

Überschriften wie „First Name“, „Revenue (€)“ oder „2024 Sales“ brechen Importe in SQL, pandas und BI-Tools. Dieses Tool schreibt sie in kleingeschriebenes snake_case (oder camelCase oder kebab-case) um: Akzente werden entfernt, Symbole ausgeschrieben (% → pct), Namen mit führender Ziffer erhalten ein Präfix, Duplikate werden nummeriert und SQL-Schlüsselwörter entschärft.

Jede Überschrift wird per Unicode-Zerlegung von Akzenten befreit, an Leerzeichen, Satzzeichen und camelCase-Grenzen in Wörter geteilt, kleingeschrieben und mit dem gewählten Trennzeichen verbunden. Leere Überschriften werden zu column_N, Duplikate erhalten _2, _3 und so weiter, und Wörter, die mit gängigen SQL-Schlüsselwörtern kollidieren, bekommen das Suffix _col. Die Zusammenfassung listet jede Umbenennung auf, damit Sie Spalten zurückzuordnen können.

So benutzt du es

  1. Fügen Sie die CSV mit der unordentlichen Kopfzeile ein.

  2. Wählen Sie snake_case, camelCase oder kebab-case und optional eine Maximallänge.

  3. Kopieren Sie die Tabelle mit der sauberen Kopfzeile oder laden Sie sie herunter.

Häufige Fragen

Ändert es meine Daten?

Nur die erste Zeile (die Kopfzeile) wird geändert.

Warum wird an „user“ ein _col angehängt?

Wörter wie user, order, group oder index sind in vielen SQL-Dialekten reserviert und müssen gequotet werden; ein Suffix vermeidet das Problem.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
