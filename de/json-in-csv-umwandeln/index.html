So funktioniert: JSON in CSV umwandeln

API-Antworten und Exporte kommen als JSON, Analysten wollen aber Zeilen und Spalten. Fügen Sie ein JSON-Array aus Objekten ein (oder ein Objekt, das eines enthält) und erhalten Sie eine CSV mit einer Zeile pro Objekt. Verschachtelte Objekte werden zu Spalten mit Punkt wie address.city, Arrays können zu nummerierten Spalten, verbundenem Text oder JSON-Text werden.

Der Konverter liest das JSON, findet das erste Array aus Objekten, wenn Sie einen Rahmen wie {"data": [...]} eingefügt haben, und glättet jeden Datensatz, indem er rekursiv durch die Schlüssel geht. Die Spaltennamen werden über alle Datensätze gesammelt, sodass Objekte mit unterschiedlichen Schlüsseln trotzdem zusammenpassen und fehlende Werte leer bleiben. Werte werden korrekt für CSV gequotet. Ist das JSON ungültig, sehen Sie eine Meldung mit der Position des Fehlers statt eines leeren Bildschirms.

So benutzt du es

  1. Fügen Sie Ihr JSON ein oder öffnen Sie eine .json-Datei.

  2. Wählen Sie, wie verschachtelte Arrays und Objekte geglättet werden sollen.

  3. Kopieren Sie die CSV oder laden Sie sie herunter und öffnen Sie sie in Excel.

Häufige Fragen

Was ist mit tief verschachteltem JSON?

Jede Ebene wird Teil des Spaltennamens (a.b.c). Für Arrays aus Objekten innerhalb von Datensätzen wählen Sie „eine Spalte pro Element“ oder behalten sie als JSON-Text.

Werden meine Daten hochgeladen?

Nein. Die Umwandlung geschieht in Ihrem Browser, API-Antworten mit privaten Daten bleiben auf Ihrem Gerät.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
