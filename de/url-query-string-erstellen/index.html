So funktioniert: URL-Query-String erstellen

Listen Sie Parameter als key=value-Zeilen auf und erhalten Sie den kodierten Query-String, optional an eine Basis-URL angehängt. Leerzeichen, Und-Zeichen, Gleichheitszeichen, Akzente und Emoji werden korrekt maskiert, und wiederholte Schlüssel können als tag=a&tag=b, tag[]=a&tag[]=b oder tag=a,b geschrieben werden.

Jeder Schlüssel und Wert wird als UTF-8 mit Prozent-Maskierung mit encodeURIComponent kodiert, plus den Zeichen, die es auslässt (! ' ( ) *), sodass das Ergebnis in jeder URL sicher ist. Leerzeichen werden zu %20 oder zu +, wenn Sie den Formularkodierungsstil wählen. Die ganze URL erneut zu kodieren würde doppelt kodieren (%2520), also erzeugen Sie den Query-String einmal und hängen ihn an. Leere Schlüssel werden übersprungen.

So benutzt du es

  1. Geben Sie Parameter als key=value-Zeilen ein.

  2. Wählen Sie, wie Leerzeichen und wiederholte Schlüssel geschrieben werden.

  3. Kopieren Sie den Query-String oder die vollständige URL.

Häufige Fragen

%20 oder + für Leerzeichen?

%20 funktioniert überall in URLs. + bedeutet nur in formularkodierten Query-Strings (application/x-www-form-urlencoded) ein Leerzeichen.

Warum wird & zu %26?

Weil ein wörtliches & in einem Wert sonst einen neuen Parameter beginnen würde.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
