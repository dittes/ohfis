So funktioniert: QR-Code-Generator

Tippen Sie einen Link oder eine Nachricht und erhalten Sie einen QR-Code, den Sie als PNG (bis 2048 px) oder als Vektor-SVG für den Druck herunterladen können, und wählen Sie Farben und Fehlerkorrekturstufe. Der Code enthält Ihre Daten direkt: Es gibt keine Weiterleitung, kein Tracking und kein Ablaufdatum, ein gedruckter Code funktioniert also ewig.

Das QR-Symbol wird in Ihrem Browser von einem Standard-Encoder erzeugt: Der Text wird in Bytes umgewandelt, in Blöcke geteilt, mit Reed-Solomon-Fehlerkorrektur geschützt (7 %, 15 %, 25 % oder 30 % des Codes dürfen beschädigt sein und lassen sich noch scannen) und mit einer Ruhezone von vier Modulen in die Matrix gelegt. Höhere Fehlerkorrektur macht den Code dichter. Dunkle Module auf hellem Grund mit gutem Kontrast scannen am besten; invertierte oder kontrastarme Codes können bei manchen Scannern scheitern. Testen Sie den gedruckten Code immer mit einem Handy.

So benutzt du es

  1. Wählen Sie die Art des Inhalts und geben Sie ihn ein.

  2. Wählen Sie Farben und die Fehlerkorrektur.

  3. Laden Sie das PNG oder SVG herunter oder drucken Sie es.

Häufige Fragen

Laufen QR-Codes ab?

Diese nicht. Die Daten stecken im Code selbst. Codes, die über einen Dienst weiterleiten, funktionieren nicht mehr, wenn der Dienst es nicht mehr tut.

Welche Größe soll ein gedruckter QR-Code haben?

Mindestens 2 × 2 cm, mit einem leeren Rand von vier Modulen ringsum; größer zum Scannen aus der Ferne.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
