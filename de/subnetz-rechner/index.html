So funktioniert: Subnetz-Rechner (CIDR, Netzmaske, IP-Bereich)

Geben Sie 192.168.1.10/24 oder eine Adresse mit Maske wie 10.1.2.3 255.255.0.0 ein und sehen Sie Netz- und Broadcast-Adresse, ersten und letzten nutzbaren Host, die Hostanzahl, die Wildcard-Maske, die binäre Maske, die Adressklasse und ob der Bereich privat, Loopback oder öffentlich ist. Optional teilen Sie das Netz in gleich große kleinere Subnetze.

Die Präfixlänge n ergibt eine Maske aus n Einsen; die Netzadresse ist IP UND Maske, die Broadcast-Adresse Netzadresse ODER invertierte Maske, und die nutzbaren Hosts sind 2^(32−n) − 2 (Netz- und Broadcast-Adresse sind reserviert). /31-Netze (Punkt-zu-Punkt-Verbindungen, RFC 3021) haben zwei nutzbare Adressen, /32 ist ein einzelner Host. Masken müssen zusammenhängend sein, was geprüft wird. Ein /24 in /26 geteilt ergibt 4 Subnetze mit je 64 Adressen.

So benutzt du es

  1. Geben Sie eine Adresse mit Präfix (/24) oder Subnetzmaske ein.

  2. Lesen Sie die Netzdetails ab.

  3. Geben Sie optional ein längeres Präfix ein, um das Netz zu teilen.

Häufige Fragen

Wie viele Hosts hat ein /24?

254 nutzbare Hosts (256 Adressen abzüglich Netz- und Broadcast-Adresse).

Was ist eine Wildcard-Maske?

Die Umkehrung der Subnetzmaske; sie wird in Zugriffslisten von Routern verwendet (für /24 ist sie 0.0.0.255).

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
