Tabs in Leerzeichen umwandeln

Einrückung von Code auf 2, 4 oder 8 Leerzeichen oder zurück zu Tabs normalisieren.

Tool wird geladen…

So funktioniert: Tabs in Leerzeichen umwandeln

Die ausführliche Erklärung ist auf Englisch.

Mixed tabs and spaces make code and config files look broken when they move between editors. Convert leading tabs to spaces, or spaces back to tabs, with a tab width of 2, 3, 4 or 8, and strip trailing whitespace at the same time.

By default only the indentation at the start of each line is changed, so tabs that appear inside a line (for example in a TSV table) stay untouched. If you turn that off, tabs inside lines are expanded to the next tab stop, which keeps columns aligned the way an editor would display them. Converting to tabs first measures the indentation width and then writes one tab per full tab stop plus any remaining spaces.

So benutzt du es

  1. Paste your code or text.

  2. Choose the direction and the number of spaces per tab.

  3. Copy the converted text.

Häufige Fragen

Should I use tabs or spaces?

Follow your project or language convention. Spaces are the most common default; tabs let each developer choose their own display width.

Does it change tabs inside strings?

Only if you disable "Only change indentation". By default the content after the indentation is left alone.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
