So funktioniert: Kalendereinladung (.ics) erstellen

Erstellen Sie einen Termin, der sich in Outlook, Apple Kalender, Google Kalender und auf Telefonen öffnet. Geben Sie Titel, Start- und Endzeit in einer von Ihnen gewählten Zeitzone, Ort oder Videolink, Beschreibung, Teilnehmer, eine Erinnerung und optionale Wiederholung ein und laden Sie die .ics-Datei herunter, um sie an eine E-Mail anzuhängen oder auf eine Webseite zu stellen. Eine Schaltfläche öffnet denselben Termin in Google Kalender.

Die Datei folgt RFC 5545. Lokale Zeiten werden mit der Zeitzonendatenbank in UTC umgerechnet, mit korrekter Behandlung der Sommerzeitwechsel, sodass der Termin für jeden Empfänger zum richtigen Zeitpunkt erscheint. Text wird maskiert (Kommas, Semikolons, Zeilenumbrüche), und lange Zeilen werden bei 75 Bytes gefaltet, ohne Akzentzeichen zu zerteilen. Ganztägige Termine nutzen Daten statt Zeiten, und Wiederholungen nutzen eine RRULE mit einer Anzahl von Vorkommen. Alles entsteht in Ihrem Browser.

So benutzt du es

  1. Geben Sie die Termindetails ein und wählen Sie die Zeitzone.

  2. Fügen Sie optional Teilnehmer, eine Erinnerung oder eine Wiederholung hinzu.

  3. Laden Sie die .ics-Datei herunter oder öffnen Sie sie in Google Kalender.

Häufige Fragen

Wie sende ich eine Kalendereinladung per E-Mail?

Hängen Sie die heruntergeladene .ics-Datei an Ihre Nachricht an. Die meisten E-Mail-Apps zeigen beim Öffnen eine Schaltfläche „Zum Kalender hinzufügen“.

Stimmt die Zeit in anderen Zeitzonen?

Ja. Die Zeit wird in UTC gespeichert, und jede Kalender-App zeigt sie in der Zone des Empfängers.

Werden meine Dateien hochgeladen?

Nein. Die Datei wird von deinem eigenen Browser geöffnet und verarbeitet. Das kannst du selbst prüfen: Öffne beim Arbeiten den Netzwerk-Tab deines Browsers oder trenne die Internetverbindung, nachdem die Seite geladen ist.

Ist dieses Tool kostenlos?

Ja, vollständig. Es gibt keine Anmeldung, keinen Bezahltarif und kein Wasserzeichen auf deinen Dateien.
