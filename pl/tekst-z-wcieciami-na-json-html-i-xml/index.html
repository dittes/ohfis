Jak działa: Tekst z wcięciami na JSON, HTML i XML

Zapisz drzewo w prosty sposób (jeden element w wierszu, wcięciami pokazującymi hierarchię) i zamień je na format strukturalny. Typowe zastosowania: struktura menu strony, drzewo folderów, struktura organizacji lub spis treści.

Konwerter czyta wcięcie każdego wiersza (tabulatory liczą się jako wybrana liczba spacji), opcjonalnie ignorując znaczniki list jak „-”, „*” lub „1.”, i buduje drzewo za pomocą stosu: wiersz wcięty głębiej staje się dzieckiem poprzedniego, a wiersz na tej samej lub mniejszej głębokości zamyka gałęzie powyżej. Drzewo jest następnie serializowane jako JSON z polami text i children, zagnieżdżone HTML <ul>, elementy XML, lista Markdown lub YAML.

Jak z tego korzystać

  1. Wpisz lub wklej konspekt, wcinając dzieci tabulatorami lub spacjami.

  2. Wybierz format wyjściowy.

  3. Skopiuj wygenerowaną strukturę.

Najczęstsze pytania

Jak głębokie może być drzewo?

Nie ma stałego limitu. Każdy głębszy poziom wcięcia tworzy nowy poziom.

Czy radzi sobie z mieszanymi tabulatorami i spacjami?

Tabulatory są zamieniane na ustawioną liczbę spacji, więc mieszane wcięcia działają, o ile wizualna głębokość jest spójna.

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.
