Minifikator CSS, HTML i JSON

Usuń komentarze i białe znaki, by zmniejszyć CSS, HTML lub JSON.

Ładowanie narzędzia…

  • Bez przesyłania
  • Za darmo
  • Bez konta
  • Po załadowaniu działa offline

Jak działa: Minifikator CSS, HTML i JSON

Wklej CSS, HTML lub JSON i otrzymaj zwartą wersję bez komentarzy i zbędnych białych znaków, z rozmiarem przed i po. CSS traci też zbędne średniki i jednostki przy zerze oraz dostaje krótkie kolory szesnastkowe; HTML zachowuje zawartość bloków pre, textarea, script i style bez zmian.

To bezpieczny, ostrożny minifikator: usuwa tylko to, co nie zmienia działania kodu, i zachowuje ciągi znaków, tekst preformatowany i komentarze warunkowe. Niczego nie zmienia nazw i nie przepisuje JavaScriptu; do tego użyj narzędzia budującego. Zawsze testuj wynik, zwłaszcza HTML z odstępami między znacznikami liniowymi.

Jak z tego korzystać

  1. Wklej kod.

  2. Sprawdź wykryty typ (lub wybierz go).

  3. Skopiuj zminifikowany wynik i porównaj rozmiary.

Najczęstsze pytania

Czy minifikuje JavaScript?

Nie. Bezpieczna minifikacja JavaScriptu wymaga pełnego parsera; użyj narzędzia budującego, jak esbuild lub terser.

Czy minifikacja HTML może zepsuć stronę?

Rzadko: odstępy między elementami liniowymi mogą mieć znaczenie. Narzędzie zachowuje pojedyncze spacje między treścią liniową; przetestuj stronę.

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.

Może Ci się przydać

Formatowanie i walidacja JSON Formatuj, minimalizuj, sortuj i waliduj JSON, z dokładną pozycją błędu. Optymalizator i minifikator SVG Zmniejsz pliki SVG, usuwając śmieci edytora i zaokrąglając liczby, z podglądem. Kompresor obrazów (zmniejsz rozmiar zdjęć) Zmniejsz pliki JPG, PNG i WebP z regulowaną jakością i zobacz oszczędność. Porównywanie tekstów (diff) Porównaj dwa teksty i zobacz każde dodane lub usunięte słowo lub linię.
