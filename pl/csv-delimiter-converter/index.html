Zmiana separatora CSV

Wykryj separator pliku CSV i zamień go na przecinek, średnik, tabulator lub kreskę.

Jak działa: Zmiana separatora CSV

Szczegółowe wyjaśnienie jest po angielsku.

Excel in Germany, France or Poland saves CSV files with semicolons, US tools expect commas, databases like tabs. If a file opens as one long column, the separator is wrong. This tool detects the delimiter of your file and rewrites it with the one you need, converting CSV to TSV and back without breaking cells that contain commas, quotes or line breaks.

Detection samples the first lines of the file and counts how often each candidate (comma, semicolon, tab, pipe) appears outside quotation marks. The delimiter that appears the same number of times on the most lines wins. The file is then parsed with a full RFC 4180 reader (quoted fields, doubled quotes, line breaks inside cells), and written out again with the new separator, quoting only the cells that need it. Options add quotes everywhere, Windows line endings or a UTF-8 BOM so that Excel shows accents correctly.

Jak z tego korzystać

  1. Paste your data or open a file. The detected separator is shown.

  2. Choose the output separator under "Output format".

  3. Copy the result or download it as a new file.

Najczęstsze pytania

Why does my CSV open in one column in Excel?

Excel expects the list separator of your regional settings (semicolon in many European countries). Convert the file to that separator, or use Data → From Text/CSV and choose the delimiter.

Will commas inside cells be broken?

No. Cells that contain the separator are wrapped in quotation marks, exactly as the CSV standard requires.

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.
