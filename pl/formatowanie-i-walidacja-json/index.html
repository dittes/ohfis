Formatowanie i walidacja JSON

Formatuj, minimalizuj, sortuj i waliduj JSON, z dokładną pozycją błędu.

Ładowanie narzędzia…

  • Bez przesyłania
  • Za darmo
  • Bez konta
  • Po załadowaniu działa offline

Jak działa: Formatowanie i walidacja JSON

Wklej JSON i otrzymaj go z wcięciami, zminimalizowany lub z posortowanymi kluczami, albo zobacz dokładnie, gdzie jest niepoprawny: wiersz, kolumnę i czego oczekiwano, z feralnym wierszem i wskaźnikiem. Opcja akceptuje JSON z komentarzami i końcowymi przecinkami, jak w plikach konfiguracyjnych.

Walidacja używa własnego małego parsera do wyjaśniania błędów, bo przeglądarki zgłaszają je różnie lub bez pozycji. Dane są parsowane i zapisywane ponownie w przeglądarce; liczby zachowują dokładność JavaScript, więc liczby całkowite powyżej 9 007 199 254 740 991 mogą tracić cyfry. Statystyki pokazują typ, liczbę kluczy, głębokość zagnieżdżenia i rozmiar.

Jak z tego korzystać

  1. Wklej JSON lub otwórz plik.

  2. Wybierz wcięcie, minimalizację lub sortowanie kluczy.

  3. Skopiuj lub pobierz wynik albo napraw pokazany błąd.

Najczęstsze pytania

Dlaczego pojawia się „Trailing comma”?

Ścisły JSON nie dopuszcza przecinka po ostatnim elemencie. Usuń go lub zaznacz opcję zezwalającą na komentarze i końcowe przecinki.

Czy duże liczby są bezpieczne?

Liczby powyżej 2^53 tracą w JavaScript dokładność. Trzymaj takie wartości jako ciągi znaków, jeśli liczą się dokładne cyfry.

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.
