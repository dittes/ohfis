Konwerter CSV na SQL INSERT

Zamień wiersze arkusza na instrukcje INSERT lub UPDATE dla MySQL, PostgreSQL, SQLite lub SQL Server.

Ładowanie narzędzia…

  • Bez przesyłania
  • Za darmo
  • Bez konta
  • Po załadowaniu działa offline

Jak działa: Konwerter CSV na SQL INSERT

Wklej wiersze z arkusza i otrzymaj SQL do uruchomienia: CREATE TABLE z odgadniętymi typami kolumn, zbiorcze INSERT-y lub jeden UPDATE na wiersz z użyciem kolumny klucza. Cytowanie nazw tabel i kolumn zależy od wybranej bazy (odwrócone apostrofy, cudzysłowy lub nawiasy kwadratowe).

Typy kolumn są wnioskowane z danych: liczby całkowite, dziesiętne, wartości logiczne, daty, znaczniki czasu, w przeciwnym razie tekst; kolumny z zerami wiodącymi zostają tekstem, więc kody pocztowe są bezpieczne. Ciągi są ucieczkowane przez podwojenie apostrofów (i backslashy dla MySQL), puste komórki mogą stać się NULL, a ciągi SQL Server dostają przedrostek N dla Unicode. INSERT-y są dzielone na paczki ustawionej wielkości. Zawsze przejrzyj wygenerowany SQL, zanim uruchomisz go na produkcyjnej bazie.

Jak z tego korzystać

  1. Wklej CSV i wpisz nazwę tabeli.

  2. Wybierz bazę danych, INSERT lub UPDATE i czy tworzyć tabelę.

  3. Skopiuj SQL lub pobierz plik .sql.

Najczęstsze pytania

Czy SQL jest bezpieczny przed wstrzyknięciem?

Wartości są ucieczkowane, ale wynik jest przeznaczony do skryptów importu, które kontrolujesz. Nigdy nie wklejaj niezaufanych danych do skryptu uruchamianego bez przeglądu.

Jak wybierane są typy?

Na podstawie wartości w każdej kolumnie. Sprawdź CREATE TABLE i dostosuj typy, np. precyzję DECIMAL.

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.
