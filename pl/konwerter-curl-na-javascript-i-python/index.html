Jak działa: Konwerter cURL na JavaScript i Python

Dokumentacje API i narzędzia deweloperskie przeglądarki podają polecenia curl. Wklej jedno, a otrzymasz równoważny kod JavaScript fetch i Python requests z tą samą metodą, nagłówkami, treścią, uwierzytelnianiem basic i polami formularza.

Polecenie jest dzielone na słowa według reguł cytowania powłoki (apostrofy i cudzysłowy, kontynuacje wierszy backslashem, ciągi $'…'), a opcje są interpretowane: -X, -H, -d / --data-raw / --data-binary, --json, -u, -F, -A, -e, -b, -k, -L i inne; opcje niezmieniające żądania (-s, -v, -o, --compressed) są ignorowane. Treści JSON są rozpoznawane i generowane jako JSON.stringify(...) lub słownik Pythona (true/false/null stają się True/False/None); uwierzytelnianie basic staje się nagłówkiem Authorization lub argumentem auth=. Sprawdź wygenerowany kod przed uruchomieniem: sekrety z polecenia trafiają do Twojego kodu.

Jak z tego korzystać

  1. Wklej polecenie curl (w przeglądarce: karta Sieć → prawy przycisk na żądaniu → Kopiuj jako cURL).

  2. Przeczytaj wygenerowany JavaScript i Python.

  3. Skopiuj potrzebny kod.

Najczęstsze pytania

Które opcje curl są obsługiwane?

Metoda, nagłówki, dane, JSON, uwierzytelnianie, formularze, user agent, referer, ciasteczka, przekierowania i tryb niezabezpieczony. Nieobsługiwane opcje wpływające na wynik są zgłaszane, gdy to możliwe.

Czy moje polecenie jest dokądś wysyłane?

Nie. Konwersja działa w przeglądarce, co ma znaczenie, bo polecenia curl często zawierają tokeny.

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.
