Narzędzia pomocnicze IT i web

Hashe, enkodery, cron, JWT, kolory, sieci i fragmenty webowe. Każde narzędzie działa w przeglądarce. Nic, co wkleisz lub otworzysz, nie jest przesyłane.

Generator sum kontrolnych plików (SHA-256, MD5, SHA-1) Oblicz i porównaj hashe plików w przeglądarce, aby zweryfikować pobrania. Kalkulator podsieci (CIDR, maska, zakres IP) Sieć, broadcast, użyteczne hosty i podział na podsieci dla dowolnego zakresu IPv4. Tłumacz wyrażeń cron Przetłumacz harmonogramy cron na zrozumiały język i zobacz najbliższe uruchomienia. Kody statusu HTTP – ściągawka Wyszukaj każdy kod statusu HTTP z prostym wyjaśnieniem i poradą. Konwerter cURL na JavaScript i Python Zamień polecenie curl na działający kod fetch i Python requests. Dekoder ciągu User-Agent Sprawdź przeglądarkę, system, urządzenie i silnik z ciągu user-agent. Enkoder i dekoder encji HTML Zamień znaki specjalne na encje HTML i z powrotem. Enkoder i dekoder Base64 (tekst i pliki) Koduj i dekoduj Base64 i adresy data URL, dla tekstu i plików. Konwerter kolorów (HEX, RGB, HSL, CMYK) Konwertuj kolory między HEX, RGB, HSL, HSV i CMYK, z selektorem i pipetą. Generator UUID / GUID (v4 i v7) Generuj partie bezpiecznych losowych UUID, także sortowalnych w czasie v7. Konwerter systemów liczbowych (binarny, ósemkowy, dziesiętny, hex) Konwertuj liczby całkowite między podstawami 2–36, o dowolnej wielkości. Generator nagłówka Basic Auth Utwórz nagłówek Authorization: Basic z nazwy użytkownika i hasła. Kalkulator przezroczystości hex (krycie na hex) Zamień procenty krycia na dwucyfrowe wartości alfa hex, np. 50% = 80. Generator znacznika meta viewport Zbuduj poprawny znacznik viewport dla stron responsywnych. Generator znaczników HTML favicony Wygeneruj znaczniki link i manifest dla ikon na desktop i mobile. Kreator parametrów zapytania URL Zamień pary klucz-wartość na poprawnie zakodowany ciąg zapytania URL. Generator adresów URL omijających cache Dodaj parametr wersji lub znacznik czasu, aby przeglądarki pobrały najnowszy plik. Sprawdzanie wygaśnięcia certyfikatu SSL i przypomnienie Odczytaj certyfikat, zobacz ile dni zostało i pobierz przypomnienia do kalendarza. Analizator nagłówków e-mail Prześledź trasę wiadomości, opóźnienia oraz wyniki SPF, DKIM i DMARC. Generator i walidator robots.txt Utwórz plik robots.txt lub sprawdź istniejący pod kątem błędów składni. Walidator i formater sitemap XML Zwaliduj sitemapę względem standardu i sformatuj ją. Podgląd Open Graph i udostępniania Zobacz podgląd linku na Facebooku, X, LinkedIn i Slacku i pobierz znaczniki meta. Generator cienia CSS box-shadow Projektuj warstwowe cienie wizualnie i kopiuj czysty CSS. Wyjaśnianie i testowanie wyrażeń regularnych Rozłóż wyrażenie regularne na zrozumiałe części i testuj na żywo. Wyszukiwarka numerów portów (TCP/UDP) Sprawdź, jaka usługa używa portu i jaki port ma dana usługa. Wyszukiwarka typów MIME (rozszerzenie do Content-Type) Znajdź właściwy Content-Type dla rozszerzenia pliku lub rozszerzenie dla typu MIME. Generator rekordów SPF i DMARC Zbuduj rekordy TXT DNS, które chronią e-maile Twojej domeny przed podszywaniem. Plac zabaw i ściągawka CSS Flexbox Przeklikaj ustawienia flexbox, zobacz wynik na żywo i skopiuj CSS. Tester podpisu webhooka (HMAC SHA-256) Oblicz podpisy webhooków w stylu GitHub, Stripe i Slack i sprawdź otrzymany. Konwerter czcionek (TTF/OTF na WOFF i z powrotem) Konwertuj plik czcionki na WOFF dla stron lub rozpakuj WOFF do TTF/OTF. Formatowanie i walidacja JSON Formatuj, minimalizuj, sortuj i waliduj JSON, z dokładną pozycją błędu. Konwerter JSON, YAML i XML Konwertuj między JSON, YAML i XML w obu kierunkach. Formatowanie SQL (upiększanie) Spraw, by zapytania SQL były czytelne dzięki wcięciom i podziałom wierszy. Tester wyrażeń regularnych (JavaScript) Testuj wyrażenie regularne na żywo: dopasowania, grupy i zamianę. Podgląd Markdown (na żywo) Zobacz renderowany Markdown podczas pisania i skopiuj HTML. Minifikator CSS, HTML i JSON Usuń komentarze i białe znaki, by zmniejszyć CSS, HTML lub JSON. Generator Lorem Ipsum Generuj tekst zastępczy w akapitach, zdaniach lub słowach. Wykrywanie typu pliku (rozpoznaj plik) Sprawdź, czym naprawdę jest plik, po zawartości, a nie po nazwie. Generator drzewa folderów (struktura jako tekst) Zamień folder lub listę ścieżek w drzewo tekstowe do dokumentacji.

Najczęstsze pytania

Czy moje pliki są gdzieś przesyłane?

Nie. Plik otwiera i przetwarza Twoja własna przeglądarka. Możesz to sprawdzić: otwórz kartę sieci w przeglądarce podczas pracy albo odłącz internet po załadowaniu strony.

Czy to narzędzie jest darmowe?

Tak, w całości. Nie ma rejestracji, płatnej wersji ani znaku wodnego na plikach.

Prywatność Nota prawna Działa w przeglądarce. Bez przesyłania, bez konta, bez śledzenia.
