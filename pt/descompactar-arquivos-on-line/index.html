Como funciona Descompactar arquivos on-line (extrator de ZIP, TAR e GZ)

Drop a ZIP, TAR, TAR.GZ or GZ file and see every file inside with its size. Filter by name, save a single file with one click or tick several files and save them as a new, smaller ZIP. This is handy on a locked-down computer, on a phone or for a quick look into an archive you do not trust enough to unpack on your disk.

The list is read from the archive’s index without unpacking anything; a file is only decompressed when you save it, so even big archives open at once. The tool warns about paths that try to leave the target folder (such as "../") and about files that expand to an absurd size compared to their packed size, which are typical signs of malicious archives. Password-protected ZIPs, RAR, 7z, bz2 and xz are not supported and are reported clearly.

Como usar

  1. Drop the archive.

  2. Filter the list or tick the files you want.

  3. Save single files or the selection as a ZIP.

Perguntas frequentes

Can it open RAR or 7z files?

No, only ZIP, TAR and GZ. RAR and 7z need a desktop program such as 7-Zip.

Can it open password-protected ZIPs?

No. Encrypted ZIPs are not supported by this tool.

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.
