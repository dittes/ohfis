Como funciona Calculadora de alfa hexadecimal (opacidade em hexa)

Add transparency to a hex colour: enter the opacity in percent, get the two-digit suffix and, with a base colour, the complete 8-digit code (#2557D680). A table lists the usual steps from 0 to 100 percent.

The alpha channel runs from 0 to 255, so hex alpha = round(opacity ÷ 100 × 255), written in base 16: 50% → 127.5 → 128 → 80, 80% → 204 → CC. CSS and browsers use #RRGGBBAA (alpha last); Android resources use #AARRGGBB (alpha first), so check which one your platform expects.

Como usar

  1. Enter the opacity in percent.

  2. Optionally enter the base colour.

  3. Copy the suffix or the complete colour.

Perguntas frequentes

What is 50% opacity in hex?

80 (decimal 128), so #000000 at half opacity is #00000080.

Does Android use the same order?

No: Android writes alpha first (#80000000).
