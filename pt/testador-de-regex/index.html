Como funciona Testador de regex (JavaScript)

Type a pattern and a text and see every match highlighted, with its position (line and column), numbered groups and named groups. Switch the flags (g, i, m, s, u) and try a replacement such as <$1> to see the result. Together with the Regex Explainer it helps you build and understand patterns.

The test uses the JavaScript regular-expression engine of your browser and runs in a background worker that is stopped after two seconds, so a pattern that backtracks catastrophically (for example (a+)+ on a long text) cannot freeze the page; you get a message instead. Other engines (PCRE, Python, .NET) differ in details such as lookbehind and named-group syntax.

Como usar

  1. Enter the pattern and choose the flags.

  2. Paste or type the test text.

  3. Read the highlighted matches and groups, and try a replacement.

Perguntas frequentes

Why does it say the pattern took too long?

Nested repeats such as (a+)+ or (.*)* can take exponential time on some inputs. Make the pattern more specific.

Will my pattern work in Python or PHP?

Often, but not always. Features like lookbehind, named groups and flags differ between engines; test in your target language.

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.
