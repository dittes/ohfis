Como funciona Gerador de QR Code vCard (QR de contato)

Put your name, company, phone numbers, email, website and address into a QR code for business cards, email signatures or conference badges. Scanning it offers to save the contact straight into the phone's address book.

The code holds a vCard 3.0 record (BEGIN:VCARD … END:VCARD) with the structured name (N), formatted name (FN), organisation, title, telephone numbers (digits only, with the international +), email, URL, work address and note. Special characters such as commas, semicolons and line breaks are escaped as the standard requires. The more fields you fill in, the denser the code, and the larger it needs to be printed to scan reliably; fewer fields mean easier scanning. Everything is generated locally.

Como usar

  1. Fill in the fields you want to share.

  2. Download the QR code or print it.

  3. Scan it with a phone to test how the contact looks.

Perguntas frequentes

How big should the QR code be on a business card?

At least 2 × 2 cm. Keep the content short (name, phone, email) for a code that scans easily when small.

Is the contact stored online?

No. The data is inside the code itself, so it works forever and no service is involved.

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.
