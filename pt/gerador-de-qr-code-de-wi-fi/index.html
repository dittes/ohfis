Como funciona Gerador de QR Code de Wi-Fi

Enter the network name and password, choose the security type and get a QR code that iPhones and Android phones understand: the camera app offers to join the network. Download it as PNG or SVG, or print it for the office, the cafe or the guest room.

The code contains a standard Wi-Fi string, WIFI:T:WPA;S:name;P:password;; , in which the special characters \ ; , : " in the name and password are escaped with a backslash. The QR code is generated locally with a standard encoder (error correction level selectable, quiet zone included), so the password is never sent anywhere. Anyone who scans the printed code gets the password, so use a guest network and change the password when needed.

Como usar

  1. Enter the network name, security type and password.

  2. Download or print the QR code.

  3. Test it with a phone before putting it up.

Perguntas frequentes

Which security type should I choose?

WPA/WPA2/WPA3 for almost every modern router. WEP is obsolete and "no password" is for open networks.

Is the password visible in the code?

Yes, to anyone who scans it. That is the point; use a separate guest network.

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.
