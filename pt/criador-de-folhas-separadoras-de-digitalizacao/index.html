Como funciona Criador de folhas separadoras de digitalização (digitalização em lote)

Scanning a stack of paperwork in one go is fast, but the pages need to be split into documents afterwards. Print numbered separator sheets, put one between every two documents, scan the whole stack and let your scanning software (or you) split at the sheets. Set the number of sheets, a label prefix, the first number and the paper size; every page has a black title band, a huge label such as DOC-001 and optionally a QR code with the same label.

The PDF is generated in your browser: the label is the prefix plus a zero-padded number, the QR code is drawn as vector squares from the label text (Reed-Solomon level M) so it scans reliably even after photocopying, and the text uses an embedded font. Many document scanners and apps (and tools such as Paperless-ngx) can split at QR or barcodes; if yours does not, the huge label makes the separators easy to find and remove by eye. Use coloured paper for extra contrast. No data is sent anywhere.

Como usar

  1. Set the number of sheets, label prefix and paper.

  2. Create the PDF and print it, preferably on coloured paper.

  3. Put a sheet between documents and scan the stack.

Perguntas frequentes

Which software splits at the QR codes?

For example Paperless-ngx, many scanner utilities and some mobile scanner apps; check yours for "barcode separator".

Do I need the QR code?

No. Untick it for plain sheets with a big label.

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.
