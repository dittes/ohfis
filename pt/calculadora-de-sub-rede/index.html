Como funciona Calculadora de sub-rede (CIDR, máscara, faixa de IP)

Enter 192.168.1.10/24 or an address with a mask such as 10.1.2.3 255.255.0.0 and see the network and broadcast address, the first and last usable host, the number of hosts, the wildcard mask, the binary mask, the address class and whether the range is private, loopback or public. Optionally split the network into equal smaller subnets.

The prefix length n gives a mask of n one-bits; the network address is the IP AND the mask, the broadcast address is the network OR the inverted mask, and the usable hosts are 2^(32−n) − 2 (the network and broadcast addresses are reserved). /31 networks (point-to-point links, RFC 3021) have two usable addresses and /32 is a single host. Masks must be contiguous, which is validated. Splitting a /24 into /26 gives 4 subnets of 64 addresses each.

Como usar

  1. Enter an address with a prefix (/24) or a subnet mask.

  2. Read the network details.

  3. Optionally enter a longer prefix to split the network.

Perguntas frequentes

How many hosts does a /24 have?

254 usable hosts (256 addresses minus the network and broadcast address).

What is a wildcard mask?

The inverse of the subnet mask; used in router access lists (for /24 it is 0.0.0.255).
