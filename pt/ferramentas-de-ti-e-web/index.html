IT and web helper tools

Hashes, encoders, cron, JWT, colours, networks and web snippets. Cada ferramenta funciona no seu navegador. Nada do que você cola ou abre é enviado.

Gerador de checksum de arquivo (SHA-256, MD5, SHA-1) Calcule e compare hashes de arquivos no navegador para verificar downloads. Calculadora de sub-rede (CIDR, máscara, faixa de IP) Rede, broadcast, hosts utilizáveis e divisão em sub-redes para qualquer faixa IPv4. Tradutor de expressões cron Traduza agendamentos cron para linguagem simples e veja os próximos horários de execução. Referência de códigos de status HTTP Pesquise todos os códigos de status HTTP com uma explicação simples e uma correção. Conversor de cURL para JavaScript e Python Transforme um comando curl em código fetch e Python requests funcional. Decodificador de string User-Agent Descubra navegador, sistema, dispositivo e motor a partir de uma string user-agent. Codificador e decodificador de entidades HTML Converta caracteres especiais em entidades HTML e vice-versa. Codificador e decodificador Base64 (texto e arquivos) Codifique ou decodifique Base64 e URLs de dados, para texto e para arquivos. Conversor de cores (HEX, RGB, HSL, CMYK) Converta cores entre HEX, RGB, HSL, HSV e CMYK, com seletor e conta-gotas. Gerador de UUID / GUID (v4 e v7) Gere lotes de UUIDs aleatórios seguros, incluindo v7 ordenáveis por tempo. Conversor de base numérica (binário, octal, decimal, hexa) Converta inteiros entre as bases 2 a 36, de tamanho arbitrário. Gerador de cabeçalho Basic Auth Crie o cabeçalho Authorization: Basic a partir de um usuário e uma senha. Calculadora de alfa hexadecimal (opacidade em hexa) Converta porcentagens de opacidade em valores alfa hexadecimais de dois dígitos, como 50% = 80. Gerador de tag meta viewport Crie uma tag viewport correta para páginas responsivas. Gerador de tags HTML de favicon Gere as tags link e o manifesto para ícones de desktop e celular. Construtor de query string de URL Transforme pares chave-valor em uma query string de URL corretamente codificada. Gerador de URL anti-cache Acrescente um parâmetro de versão ou carimbo de data/hora para os navegadores buscarem o arquivo mais recente. Verificador de validade de certificado SSL e lembrete Leia um certificado, veja quantos dias restam e baixe lembretes de calendário. Analisador de cabeçalhos de e-mail Rastreie o caminho de um e-mail, os atrasos e os resultados de SPF, DKIM e DMARC. Gerador e validador de robots.txt Crie um robots.txt ou confira um existente em busca de erros de sintaxe. Validador e formatador de sitemap XML Valide um sitemap conforme o padrão e formate-o. Prévia de Open Graph e compartilhamento social Veja como um link aparece no Facebook, X, LinkedIn e Slack e obtenha as meta tags. Gerador de sombra de caixa CSS Projete sombras de caixa em camadas visualmente e copie CSS limpo. Explicador e testador de expressões regulares Divida uma expressão regular em partes em linguagem simples e teste-a ao vivo. Consulta de número de porta (portas TCP/UDP comuns) Descubra qual serviço usa uma porta e qual porta um serviço usa. Consulta de tipo MIME (extensão de arquivo para Content-Type) Encontre o Content-Type correto para uma extensão de arquivo ou a extensão de um tipo MIME. Gerador de registros SPF e DMARC Crie os registros DNS TXT que impedem outros de falsificar o e-mail do seu domínio. Laboratório e guia rápido de CSS Flexbox Percorra as configurações do flexbox, veja o resultado ao vivo e copie o CSS. Testador de assinatura de webhook (HMAC SHA-256) Calcule assinaturas de webhook no estilo GitHub, Stripe e Slack e confira a que você recebeu. Conversor de fontes (TTF/OTF para WOFF e vice-versa) Converta um arquivo de fonte para WOFF para sites ou descompacte WOFF em TTF/OTF. Formatador e validador de JSON Formate, minifique, ordene e valide JSON, com a posição exata do erro. Conversor de JSON, YAML e XML Converta entre JSON, YAML e XML nos dois sentidos. Formatador e embelezador de SQL Deixe consultas SQL legíveis com indentação e quebras de linha. Testador de regex (JavaScript) Teste uma expressão regular ao vivo: correspondências, grupos e substituição. Prévia de Markdown (ao vivo) Veja o Markdown renderizado enquanto digita e copie o HTML. Minificador de CSS, HTML e JSON Remova comentários e espaços para deixar CSS, HTML ou JSON menores. Gerador de Lorem Ipsum Gere texto de preenchimento por parágrafos, frases ou palavras. Detector de tipo de arquivo (identifique qualquer arquivo) Descubra o que um arquivo realmente é, pelo conteúdo e não pelo nome. Gerador de árvore de pastas (estrutura de diretórios em texto) Transforme uma pasta ou uma lista de caminhos em uma árvore de texto para documentação.

Perguntas frequentes

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.

Privacidade Aviso legal Funciona no seu navegador. Sem upload, sem conta, sem rastreamento.
