Como funciona Decodificador de string User-Agent

Paste a user-agent string from a log file or support ticket and see the browser and version, operating system, device type, rendering engine and whether it is a bot. Your own user agent is prefilled.

The parser applies ordered rules, because user agents imitate each other: every Chrome-based browser says "Mozilla" and "Safari", Edge adds "Edg/", Opera "OPR/" and iPhone Chrome says "CriOS". It therefore checks the most specific tokens first, then reads the OS (Windows NT 10.0 is reported as "10 / 11" because both use it), device class (mobile, tablet, TV, bot) and the Android model. Bots are recognised by common crawler tokens. User-agent strings can be faked and Chrome is gradually freezing their detail, so use them for diagnostics, not for security or feature decisions.

Como usar

  1. Paste a user-agent string (or use yours).

  2. Read the decoded browser, system and device.

  3. Treat bot results with care: strings can be faked.

Perguntas frequentes

Why does every browser say Mozilla?

For historical compatibility: early websites served better pages to Mozilla, so every browser claimed to be one.

Why does Windows 11 show as Windows 10?

Both report NT 10.0 in the user agent. Windows 11 can only be told apart with client hints.

Meus arquivos são enviados?

Não. O arquivo é aberto e processado pelo seu próprio navegador. Você mesmo pode conferir: abra a aba de rede do navegador enquanto usa a ferramenta ou desconecte da internet depois que a página carregar.

Esta ferramenta é gratuita?

Sim, totalmente. Não há cadastro, plano pago nem marca-d'água nos seus arquivos.
