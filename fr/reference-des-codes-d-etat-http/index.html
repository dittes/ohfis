Comment fonctionne Référence des codes d'état HTTP

Search by number or keyword to see what a status code means and what to do about it. All codes from 1xx to 5xx in the IANA registry that matter in practice are listed, grouped by class, each with a short explanation and a hint for fixing it.

The first digit gives the class: 1xx informational, 2xx success, 3xx redirection, 4xx client error and 5xx server error. For each code the entry explains what the server is saying and the most common cause and fix: for example 502 means a proxy got an invalid answer from the application behind it, 504 means the application was too slow, and 429 means you are rate-limited and should wait for Retry-After. The search covers codes, names and descriptions.

Mode d'emploi

  1. Type a code (404) or a keyword (redirect, timeout).

  2. Optionally filter by class.

  3. Read the explanation and what to try.

Questions fréquentes

What is the difference between 401 and 403?

401 means you are not authenticated (no or invalid credentials). 403 means the server knows who you are but you are not allowed.

301 or 302 for redirects?

301 for permanent moves (search engines transfer ranking), 302 or 307 for temporary ones.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
