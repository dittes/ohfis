Ajouter un préfixe ou un suffixe aux lignes

Ajoutez du texte, des nombres ou des balises avant ou après chaque ligne en une seule étape.

Chargement de l'outil…

  • Aucun envoi
  • Gratuit
  • Sans compte
  • Fonctionne hors ligne une fois chargé

Comment fonctionne Ajouter un préfixe ou un suffixe aux lignes

Wrap every line in quotes, add a bullet, append a semicolon or number a list: type what should go before and after each line and it is applied to thousands of lines at once. Use {n} anywhere in the prefix or suffix to insert a counter that can start at any number and be zero-padded.

The text is split into lines and the prefix and suffix are added to each one. Empty lines are skipped by default so blank separators stay blank. The counter increases by one per non-empty line and is padded with leading zeros to the number of digits you choose (for example 007).

Mode d'emploi

  1. Paste your lines.

  2. Enter the text to add before and after, using {n} for a counter if you need one.

  3. Copy the result.

Questions fréquentes

How do I number lines?

Tick "Insert counter", then put {n} into the prefix, for example "{n}. ". Set the start number and the number of digits.

Can I add text to the end only?

Yes. Leave the prefix empty and fill in only the suffix.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
