Générateur de fausses données

Générez des noms, e-mails et adresses réalistes pour des données de test au lieu de Lorem Ipsum.

Chargement de l'outil…

  • Aucun envoi
  • Gratuit
  • Sans compte
  • Fonctionne hors ligne une fois chargé

Comment fonctionne Générateur de fausses données

Fill a prototype, a demo database or a mock-up with believable people, companies, addresses, phone numbers, dates and amounts instead of "Lorem ipsum". Choose the fields, the number of records (up to 1,000) and English or German style names, then copy the table or download CSV or JSON.

Records are assembled from curated lists of common first names, surnames, street names and cities using a seeded random generator, so the data looks realistic but is not taken from any real person. Email addresses use the reserved domain example.com and phone numbers use ranges set aside for fiction, so test data can never reach a real inbox or phone.

Mode d'emploi

  1. Tick the fields you need and choose how many rows.

  2. Pick the name style and output format.

  3. Copy or download the data; press "Generate" for a fresh set.

Questions fréquentes

Is this data real?

No. Names and addresses are combined randomly from lists. Emails use example.com and phone numbers use fictional ranges.

Can I generate more than 1,000 rows?

Generate several batches and combine them, or use the CSV tools to merge them.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
