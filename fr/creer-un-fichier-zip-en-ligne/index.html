Créer un fichier ZIP en ligne (compresser fichiers et dossiers)

Regroupez des fichiers et des dossiers entiers dans un seul fichier ZIP.

Comment fonctionne Créer un fichier ZIP en ligne (compresser fichiers et dossiers)

Add files, drag in many at once or pick a whole folder (its sub-folders are kept), choose the compression level and download one ZIP file with the name you want. It is the quickest way to send several files as one attachment.

Files that are already compressed, such as JPG, MP3, MP4, PDF or DOCX, are stored without recompression, because squeezing them again only costs time and gains nothing. Duplicate names are renamed ("file (2).txt") and unsafe path parts are removed. The ZIP is built in your browser with the fflate library and kept in memory, so total sizes of a few hundred megabytes are fine, but gigabytes are not. There is no password option, because the classic ZIP encryption is weak; use an encrypted note or a protected PDF for secrets.

Mode d'emploi

  1. Add files or choose a folder.

  2. Name the archive and pick the compression.

  3. Download the ZIP.

Questions fréquentes

Can I add a password?

Not here. The old ZIP password scheme is easy to break; protect sensitive documents with a PDF password or an encrypted note instead.

Why is the ZIP barely smaller?

Photos, videos and most office files are already compressed, so ZIP cannot shrink them much. Text, CSV and code compress very well.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
