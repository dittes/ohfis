Aplatissez des tableaux JSON et objets imbriqués en table CSV pour Excel.

Comment fonctionne Convertisseur JSON en CSV

API responses and exports arrive as JSON, but analysts want rows and columns. Paste a JSON array of objects (or an object that contains one) and get a CSV with one row per object. Nested objects become dotted columns such as address.city, and arrays can become numbered columns, joined text or JSON text.

The converter parses the JSON, finds the first array of objects if you pasted a wrapper like {"data": [...]}, and flattens every record by walking its keys recursively. Column names are collected across all records, so objects with different keys still line up and missing values stay empty. Values are written with proper CSV quoting. If the JSON is invalid, you see a message with the position of the error instead of a blank screen.

Mode d'emploi

  1. Paste your JSON or open a .json file.

  2. Choose how nested arrays and objects should be flattened.

  3. Copy the CSV or download it and open it in Excel.

Questions fréquentes

What about deeply nested JSON?

Every level becomes part of the column name (a.b.c). For arrays of objects inside records, choose "one column per item" or keep them as JSON text.

Is my data uploaded?

No. The conversion happens in your browser, so API responses with private data stay on your device.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
