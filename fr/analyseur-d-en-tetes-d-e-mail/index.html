Comment fonctionne Analyseur d'en-têtes d'e-mail

Where did this mail come from, why did it take two hours and is the sender real? Paste the full headers and see the route as a table of hops with the time each server took, the SPF, DKIM and DMARC verdicts, and warnings when the From, Return-Path and Reply-To addresses do not match.

Headers are unfolded (continuation lines are joined) and every Received line is parsed for the sending host, receiving server, IP address, protocol and timestamp, then ordered from oldest to newest so delays between hops can be computed. The Authentication-Results header written by the receiving server provides the SPF, DKIM and DMARC results. Mismatches between the visible From domain and the envelope sender (Return-Path) or Reply-To are flagged, because phishing often relies on them; legitimate mailing services also trigger this, so judge in context. Headers never leave your browser.

Mode d'emploi

  1. Open the message source (Gmail: ⋮ → Show original) and copy the headers.

  2. Paste them here.

  3. Read the route, delays and authentication results.

Questions fréquentes

Which Received line is the first?

The last one in the list: each server adds its line on top. The tool reverses the order for you.

What do SPF, DKIM and DMARC mean?

SPF checks the sending server, DKIM checks a cryptographic signature and DMARC requires that one of them matches the visible From domain.
