Matrice d'Eisenhower avec post-it (interactive)

Classez des tâches en post-it dans les quadrants urgent/important par glisser-déposer, puis exportez ou imprimez.

Comment fonctionne Matrice d'Eisenhower avec post-it (interactive)

The Eisenhower matrix sorts tasks by two questions: is it urgent, and is it important? Do the urgent and important ones first, schedule the important but not urgent ones, delegate the urgent but unimportant ones and drop the rest. Write each task on a sticky note, drag it to the right quadrant and recolour it by person or project.

Your matrix is saved in this browser and nothing is uploaded. Download it as a PNG, copy it as Markdown for your notes, print it, or save it as a file. For a quick text-only version, use the Priority Matrix Maker.

Mode d'emploi

  1. Add a note in any quadrant and write the task.

  2. Drag notes to the quadrant where they belong, or use the menu on the note.

  3. Print the matrix or export it as PNG or Markdown.

Questions fréquentes

What belongs in "Schedule"?

Important work without a deadline pressure: planning, learning, health, relationships. It is the quadrant that makes the biggest long-term difference.

How many tasks per quadrant?

Keep the "Do first" box short. If it overflows every week, the cause is usually missing planning in "Schedule".

Does it work on a phone?

Yes. The quadrants stack, and the menu on each note moves it, because dragging is awkward on small screens.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
