Compteur de mots de document Word (DOCX)

Comptez mots, caractères, paragraphes et temps de lecture d'un fichier .docx.

Comment fonctionne Compteur de mots de document Word (DOCX)

Drop a .docx file and get the word count, characters with and without spaces, paragraphs, sentences, an estimated page count and the reading and speaking time. Options include or exclude footnotes, endnotes, headers and footers.

The text is read from the document’s XML inside the file, without opening Word, so it also works for documents you cannot or do not want to open. Text boxes, comments and tracked deletions are not counted, and the page count is only an estimate (500 words per page) because the real layout depends on fonts and margins. Counts can differ slightly from Word’s own, which has its own rules for hyphenated words and fields.

Mode d'emploi

  1. Drop the .docx file.

  2. Choose whether footnotes, headers and footers are counted.

  3. Read the numbers.

Questions fréquentes

Can it open old .doc files?

No, only .docx. Save the old file as .docx in Word or LibreOffice first.

Why does Word show a different number?

Word counts some things differently (text boxes, hyphenated words, fields). The difference is usually small.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
