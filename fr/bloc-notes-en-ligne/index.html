Bloc-notes en ligne (enregistrement automatique)

Un bloc-notes simple qui s'enregistre automatiquement dans votre navigateur, avec plusieurs blocs.

Chargement de l'outil…

  • Aucun envoi
  • Gratuit
  • Sans compte
  • Fonctionne hors ligne une fois chargé

Comment fonctionne Bloc-notes en ligne (enregistrement automatique)

A blank page for the thing you need to jot down right now: a phone number, a draft, a to-do list. Everything you type is saved after every pause, so a crash, a restart or an accidental tab close does not lose it. Use several pads, rename them and download any as a text file.

Text is stored in your browser's localStorage on this device only: nothing is uploaded and there is no account. That also means the notes are not synced to other devices, and clearing site data, using a private window or a different browser starts empty. A status line shows whether saving worked (storage can be blocked in private mode). Do not store passwords or confidential data in a notepad; use the encrypted note tool or a password manager for those.

Mode d'emploi

  1. Type in the pad; it saves automatically.

  2. Add or rename pads for different topics.

  3. Copy or download the text when you need it elsewhere.

Questions fréquentes

Where is my text stored?

Only in this browser on this device (localStorage). It is not sent to any server.

Will I lose it if I clear my browsing data?

Yes. Download important notes as a file.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
