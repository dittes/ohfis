Générateur d'URL anti-cache

Ajoutez un paramètre de version ou d'horodatage pour que les navigateurs récupèrent le dernier fichier.

Chargement de l'outil…

  • Aucun envoi
  • Gratuit
  • Sans compte
  • Fonctionne hors ligne une fois chargé

Comment fonctionne Générateur d'URL anti-cache

When you update a stylesheet or script and browsers or a CDN keep serving the old copy, a changed query string forces a fresh download. Paste the URLs, choose a timestamp, random string or fixed version and copy the busted URLs.

The parameter is set with the URL parser, so existing parameters stay and an existing ?v= is replaced, not duplicated. A timestamp changes on every click, which is ideal for testing; for production a version number or a content hash is better, because a constant URL can still be cached and a timestamp prevents caching altogether. File-name hashing (app.3f9a2c.js) is the most reliable method because some CDNs ignore query strings.

Mode d'emploi

  1. Paste the URLs, one per line.

  2. Choose the parameter name and value type.

  3. Copy the new URLs.

Questions fréquentes

Do all CDNs respect the query string?

Most do, but some are configured to ignore it. File names with a hash always work.

How do I test without caching?

Use a timestamp while developing and open the developer tools with "Disable cache" ticked.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
