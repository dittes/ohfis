Convertisseur de texte enrichi en HTML propre

Collez depuis Word ou Google Docs et obtenez un HTML propre sans styles, polices ni résidus.

Comment fonctionne Convertisseur de texte enrichi en HTML propre

Copy formatted text from Word, Google Docs, a web page or an email, paste it into the box and get clean HTML with only meaningful tags: paragraphs, headings, bold, italic, links, lists, quotes, code and simple tables. Fonts, colours, sizes, classes, ids and tracking markup are removed, so the text takes on the style of your own website. A preview and a character count show what was removed.

The tool works on what the browser puts in the editable box when you paste. The HTML is parsed into a document that is never added to the page as live content with scripts, and rebuilt from a whitelist of tags: unknown elements are unwrapped (their text is kept), scripts, styles, images, forms and frames are dropped, links are kept only for http, https, mailto and tel addresses, and all attributes except href and colspan are removed. Word and Google Docs often express bold and italic as styled spans: these are converted to <strong> and <em>. Complex layouts, nested tables, comments and tracked changes are not preserved.

Mode d'emploi

  1. Copy formatted text and paste it into the box.

  2. Choose whether to keep links, tables and headings.

  3. Copy the clean HTML.

Questions fréquentes

Why clean pasted HTML?

Word and Google Docs add styles, classes and fonts that break the design of your website and bloat the page.

Are scripts removed?

Yes. Scripts, styles, forms, frames and event attributes never survive the cleaning.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
