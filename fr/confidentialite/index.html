Politique de confidentialité

Ohfis s'exécute dans votre navigateur. Vos fichiers ne sont pas envoyés, et nous n'utilisons ni analyse, ni suivi, ni cookies.

Ce qu'il advient de vos fichiers

Les fichiers que vous ouvrez sont traités dans la mémoire de votre navigateur, sur votre propre appareil. Ils ne nous sont jamais envoyés, ni à personne d'autre. Nous n'exploitons aucun serveur qui traite des fichiers.

Les outils PDF, la page d'accueil et l'aperçu des PDF portent aussi une politique de sécurité du contenu (Content Security Policy), qui demande à votre navigateur de bloquer les connexions réseau vers d'autres serveurs. Tout le code et toutes les données dont ces outils ont besoin, y compris la reconnaissance de texte, sont servis par ohfis.com lui-même.

Ce qui est stocké sur votre appareil

  • Stockage local : votre choix de thème et de langue, vos préférences d'affichage, vos favoris, vos outils récemment utilisés et les tableaux que vous enregistrez.
  • IndexedDB : un fichier que vous transmettez d'un outil PDF au suivant. Il est supprimé dès que l'outil suivant l'a ouvert.
  • Stockage du cache : les fichiers propres à l'application, pour qu'elle continue de fonctionner hors ligne.

Vous pouvez tout supprimer à tout moment dans les paramètres de votre navigateur, sous les données du site. Nous n'avons accès à rien de tout cela.

Hébergement

Ce site est hébergé sur GitHub Pages. Lorsque vous le consultez, GitHub traite des données techniques telles que votre adresse IP afin de délivrer les pages. Voir la déclaration de confidentialité de GitHub. La base juridique est notre intérêt légitime à fournir le site (art. 6, par. 1, point f du RGPD).

Vos droits

En vertu du RGPD, vous avez le droit d'accès, de rectification, d'effacement, de limitation, de portabilité des données et d'opposition, ainsi que le droit d'introduire une réclamation auprès d'une autorité de contrôle. Comme nous ne collectons pas nous-mêmes de données personnelles, nous n'avons en général rien à votre sujet. Vos questions sont les bienvenues à ohfis@dittes.info.
