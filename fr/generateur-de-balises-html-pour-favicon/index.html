Générez les balises link et le manifeste pour les icônes de bureau et de mobile.

Comment fonctionne Générateur de balises HTML pour favicon

Choose which icon files you have and get the right <link> tags, in the order browsers prefer, plus a ready web app manifest. Pair it with the Favicon & App Icon Generator to create the image files themselves.

Modern setups need little: an SVG icon (scales, supports dark mode), a 32 px .ico or PNG fallback, a 180 px apple-touch-icon and a manifest with 192 and 512 px icons for Android and installable web apps. The tags and the manifest use the folder you enter, so paths work from every page.

Mode d'emploi

  1. Enter the folder that holds your icons.

  2. Tick the icons you provide and set the theme colour.

  3. Copy the tags into <head> and save the manifest.

Questions fréquentes

Which favicon sizes do I need?

An SVG or a 32×32 PNG/ICO for browsers, 180×180 for Apple devices and 192×192 and 512×512 for Android.

Where do I put favicon.ico?

In your site's root folder; browsers ask for it there by default.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
