Générateur de sommaire Markdown

Générez un sommaire avec liens à partir des titres d'un document Markdown.

Comment fonctionne Générateur de sommaire Markdown

Paste a README or document and get a nested list of links to all its headings, ready to paste at the top. Choose which heading levels to include, bullets or numbers, and optionally insert the finished table into the document right after the title.

Headings are read line by line, skipping code blocks (so a "# comment" in a shell snippet is not mistaken for a heading), and inline formatting such as links, code and emphasis is stripped from the link text. The anchors follow GitHub's rules: lower-case, punctuation removed (letters and digits of any language are kept), spaces turned into hyphens, and duplicate headings get -1, -2 suffixes. Other renderers (GitLab, VS Code, static site generators) use very similar but not identical rules, so test the links in your target platform.

Mode d'emploi

  1. Paste your Markdown document.

  2. Choose the heading levels and list style.

  3. Copy the table of contents into your document.

Questions fréquentes

Why do some links not work on my site?

Anchor rules differ slightly between platforms. This tool uses GitHub's rules.

Are headings in code blocks ignored?

Yes.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
