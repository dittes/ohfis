Formateur et validateur JSON

Formatez, minifiez, triez et validez du JSON, avec la position exacte de l'erreur.

Chargement de l'outil…

  • Aucun envoi
  • Gratuit

  • Fonctionne hors ligne une fois chargé

Comment fonctionne Formateur et validateur JSON

Paste JSON and get it indented, minified or with sorted keys, or see exactly where it is invalid: the line, the column and what was expected, with the offending line and a pointer. An option accepts JSON with comments and trailing commas, as found in config files.

Validation uses a small parser of its own to explain errors, because browsers report them differently or without a position. The data is parsed and rewritten in your browser; numbers keep JavaScript’s precision, so integers above 9,007,199,254,740,991 can lose digits. The statistics show the type, the number of keys, the nesting depth and the size.

Mode d'emploi

  1. Paste the JSON or open a file.

  2. Choose indentation, minify or sort keys.

  3. Copy or download the result, or fix the error shown.

Questions fréquentes

Why does it say "Trailing comma"?

Strict JSON does not allow a comma after the last item. Remove it, or tick the option to allow comments and trailing commas.

Are large numbers safe?

Numbers beyond 2^53 lose precision in JavaScript. Keep such values as strings if exact digits matter.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
