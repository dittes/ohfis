Convertisseur Markdown en Word (DOCX)

Convertissez des notes Markdown en vrai document Word avec titres, listes et tableaux.

  • Aucun envoi
  • Gratuit

Comment fonctionne Convertisseur Markdown en Word (DOCX)

Paste Markdown or load a .md file and download a .docx that opens in Word, LibreOffice and Google Docs with real Heading styles (so the navigation pane and a table of contents work), bullet and numbered lists, nested lists, quotes, code blocks, tables with a shaded header row, bold, italic, inline code and clickable links.

The document is assembled in your browser as a minimal Office Open XML package (a ZIP of XML files: document, styles, numbering, relationships) using fflate. Headings map to Heading 1–6, lists to a numbering definition, links to hyperlink relationships, and special characters are escaped so no input can break the file. The page is A4 with comfortable margins and the font can be chosen. Images, footnotes and raw HTML are not supported, and complex nested constructs fall back to plain paragraphs.

Mode d'emploi

  1. Paste or open your Markdown.

  2. Set the title and font.

  3. Download the Word document.

Questions fréquentes

Do headings become real Word headings?

Yes. They use the Heading 1–6 styles, so the navigation pane and table of contents work.

Are images supported?

Not in this version.

Mes fichiers sont-ils envoyés ?

Non. Le fichier est ouvert et traité par votre propre navigateur. Vous pouvez le vérifier vous-même : ouvrez l'onglet réseau de votre navigateur pendant l'utilisation de l'outil, ou coupez internet après le chargement de la page.

Cet outil est-il gratuit ?

Oui, entièrement. Pas d'inscription, pas d'offre payante et pas de filigrane sur vos fichiers.
