Cómo funciona Conversor de tabla a Markdown

Copy a range in Excel or Google Sheets, paste it here and get a GitHub-flavoured Markdown table with aligned columns, or an unstyled HTML table. It also reads CSV, semicolon, pipe and space-separated data and can re-format an existing ragged Markdown table.

Separators are detected automatically (tab first, as used by spreadsheets), rows are padded to the same number of columns, pipe characters inside cells are escaped, and line breaks become <br>. Column alignment (left, centre, right) is written into the delimiter row, and with "align columns" each column is padded so the source looks tidy in a plain text editor. HTML output escapes special characters.

Cómo usarla

  1. Copy cells from your spreadsheet and paste them in.

  2. Choose Markdown or HTML, alignment and whether the first row is a header.

  3. Copy the table into your README, wiki or CMS.

Preguntas frecuentes

Does Markdown support merged cells?

No. Markdown tables are a simple grid. Merged cells are flattened into single cells.

Can it clean up an existing messy Markdown table?

Yes. Paste the table; the pipes are detected and the table is rebuilt with aligned columns.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
