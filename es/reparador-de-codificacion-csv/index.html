Cómo funciona Reparador de codificación CSV (UTF-8, mojibake)

"MÃ¼ller" instead of "Müller", "cafÃ©" instead of "café" and question marks where umlauts should be: these are encoding mix-ups. Open the file here and it is decoded with the right character set (detected automatically, or chosen from a list such as Windows-1252, ISO-8859-2 or UTF-16) and saved back as UTF-8, with a BOM if Excel needs one.

Garbled text of the "MÃ¼ller" kind (called mojibake) happens when UTF-8 bytes were read as Windows-1252. The repair reverses that: each character is mapped back to its original byte (including the special Windows-1252 positions such as € and “) and the bytes are decoded as UTF-8. Only words that actually look broken are changed, and the process repeats for text that was damaged twice. For files in another encoding, the bytes are decoded with the browser's TextDecoder. Detection checks whether the file is valid UTF-8, and falls back to Windows-1252 if not.

Cómo usarla

  1. Open the file, or paste the garbled text.

  2. Leave the encoding on automatic, or pick the one your file uses.

  3. Check the preview and download the UTF-8 file.

Preguntas frecuentes

What causes "Ã¼" instead of "ü"?

A UTF-8 file was opened as if it were Windows-1252 or Latin-1. Each umlaut is two bytes in UTF-8, which then show as two wrong characters.

Why add a BOM?

Excel guesses the encoding of CSV files and often chooses wrongly without a byte order mark. With the BOM it opens UTF-8 correctly.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
