Cómo funciona Conversor de CSV a JSON

Turn a spreadsheet export into JSON for an API, a test fixture or a config file. The first row becomes the keys, every other row becomes an object. Numbers and true/false are converted to real JSON types, empty cells become null, and headers with dots such as address.city can be nested into objects.

The CSV is parsed with a standards-compliant reader that understands quoted cells and line breaks. Type conversion is deliberately conservative: only values that are clean numbers (no leading zeros, so zip codes stay text) and the words true/false are converted. You can switch conversion off to keep every value as a string, choose pretty-printed JSON or compact JSON, or get JSON Lines (one object per line) for large imports.

Cómo usarla

  1. Paste your CSV or open a file. The separator is detected.

  2. Choose type conversion, nesting and formatting options.

  3. Copy the JSON or download it.

Preguntas frecuentes

Why did my zip code stay a string?

Values with leading zeros like 01234 are kept as text so that no information is lost.

What is JSON Lines?

One JSON object per line, easy to stream and import into databases and log tools.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
