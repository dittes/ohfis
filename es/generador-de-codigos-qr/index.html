Cómo funciona Generador de códigos QR

Type a link or a message and get a QR code you can download as PNG (up to 2048 px) or as a vector SVG for print, and choose colours and the error-correction level. The code contains your data directly: there is no redirect, no tracking and no expiry date, so a printed code works forever.

The QR symbol is generated in your browser by a standard encoder: the text is converted to bytes, split into blocks, protected with Reed–Solomon error correction (7%, 15%, 25% or 30% of the code can be damaged and still scan) and laid out in the matrix with a four-module quiet zone. Higher error correction makes the code denser. Dark modules on a light background with good contrast scan best; inverted or low-contrast codes may fail on some scanners. Always test the printed code with a phone.

Cómo usarla

  1. Choose the type of content and enter it.

  2. Pick colours and the error correction.

  3. Download the PNG or SVG, or print it.

Preguntas frecuentes

Do QR codes expire?

Not these. The data is stored in the code itself. Codes that redirect through a service stop working when that service does.

What size should a printed QR code be?

At least 2 × 2 cm, with a blank margin of four modules around it; larger for scanning from a distance.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
