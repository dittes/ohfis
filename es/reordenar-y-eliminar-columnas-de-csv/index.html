Arrastra columnas a un nuevo orden o quítalas antes de compartir una tabla.

Cómo funciona Reordenar y eliminar columnas de CSV

Strip a customer export down to the columns you want to share, or put the columns in the order an import template expects. Every column becomes a card: drag it, use the arrow buttons or untick it to drop the column. A live preview shows the result.

The file is parsed once; the tool keeps a list that maps each output position to an input column and whether it is kept. Reordering only changes that list, so even very wide tables respond instantly. When you copy or download, the rows are rebuilt in the chosen order and re-encoded as CSV. A "copy for Excel" button uses tabs, so the result pastes into separate cells.

Cómo usarla

  1. Paste your CSV.

  2. Drag the column cards (or use the arrows), and untick columns to delete them.

  3. Copy or download the new table.

Preguntas frecuentes

Can I do this with the keyboard?

Yes. Each column card has left and right arrow buttons and a checkbox, so no drag and drop is required.

Does it keep my data private?

Yes. The table never leaves your browser.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
