Cómo funciona Traductor de código Morse

Type a message to get dots and dashes, or paste Morse code to read it. The direction is detected automatically. Press "Play as sound" to hear the message as beeps at the speed and pitch you choose.

Letters, digits and common punctuation are converted with the International Morse table; accented letters are reduced to their base letters (ä → AE, ß → SS). Words are separated by a slash. For audio, the Web Audio API drives a sine oscillator that is switched on for a dot (one unit) or dash (three units) with short ramps to avoid clicks, using the standard timing: one unit between symbols, three between letters and seven between words.

Cómo usarla

  1. Type text or paste Morse code.

  2. Read the translation, or press "Play as sound".

  3. Adjust the speed and pitch to taste, then copy the result.

Preguntas frecuentes

How do I write a space between words in Morse?

Use a slash (/) or several spaces between words; single spaces separate letters.

How fast is 15 words per minute?

It is a comfortable speed for learners. The timing follows the standard PARIS word.
