Cómo funciona Resumidor de texto (acortar texto automáticamente)

Paste an article, report or transcript, choose how many sentences you want and get the sentences that carry most of the content, in their original order, together with the key words. It supports English, German, Polish and Czech.

This is an extractive summary: it scores each sentence by how many important words it contains (frequent words apart from common stop words), gives a small bonus to the first sentences and returns the best ones unchanged. It does not rewrite or understand the text, so it can miss the point of an argument or pick sentences that need their context. It is honest, fast and private; for a real abstract, read the result and edit it.

Cómo usarla

  1. Paste the text and choose its language.

  2. Set the number of sentences.

  3. Copy the summary.

Preguntas frecuentes

Is this AI?

No. It is a transparent word-frequency method that picks existing sentences. Nothing is generated or sent anywhere.

Why is a sentence missing that I think is important?

The method only counts words. Raise the number of sentences, or choose the language that matches the text so the stop words are ignored correctly.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
