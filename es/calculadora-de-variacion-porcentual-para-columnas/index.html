Cómo funciona Calculadora de variación porcentual para columnas

Compare this year with last year for hundreds of rows at once. Choose the old and the new value column and the tool adds a "% change" column with the rounding you want. Growth shows as positive numbers, declines as negative ones.

The formula is (new − old) ÷ |old| × 100. Using the absolute value of the old number keeps the sign meaningful even when the old value is negative. If the old value is zero the percentage is mathematically undefined, so the cell shows n/a (or 0 when both are zero) instead of a misleading figure. Rows where either value is not a number get an empty cell.

Cómo usarla

  1. Paste your CSV.

  2. Choose the old-value and new-value columns and the number of decimals.

  3. Copy or download the table with the new column.

Preguntas frecuentes

What is the difference between percent change and percentage points?

Going from 10% to 12% is a 20% increase but a 2 percentage point increase. This tool calculates percent change.

Why n/a?

You cannot divide by zero: a change from 0 to 15 has no percentage.
