Cómo funciona Generador de sombras CSS (box-shadow)

Soft, realistic shadows are built from several layers. Add as many as you like, move the sliders for offset, blur, spread, colour and opacity, switch a layer to inset and watch the preview change. Copy the finished box-shadow declaration.

Each layer becomes "x y blur spread rgba(r, g, b, a)" with an optional inset keyword, and the layers are joined with commas; the first layer is painted on top. A common recipe for natural depth is a small, sharper shadow (y 2px, blur 6px, 10% opacity) combined with a large soft one (y 8px, blur 24px, negative spread). The output uses rgba() so opacity works in every browser.

Cómo usarla

  1. Adjust the first layer, or add more layers.

  2. Pick page and box colours to judge the result.

  3. Copy the CSS.

Preguntas frecuentes

What does the spread value do?

It grows or shrinks the shadow. A negative spread with a large blur makes a soft shadow that does not spill to the sides.

How many shadows can I stack?

As many as you like, though two or three layers are usually enough.
