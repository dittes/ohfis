Cómo funciona Formateador de tablas Markdown

A Markdown table is easy to write and hard to read when the pipes do not line up. Paste your table, even one with missing outer pipes or uneven columns, and get a tidy version with every column padded to the same width. Column alignment markers (:--, :-:, --:) are preserved or can be forced.

Cells are split on pipes (escaped \| pipes stay inside cells), the delimiter row is read to learn each column's alignment, rows are padded to the same number of cells, and column widths are measured in characters, so emoji and accents are handled. Compact mode removes padding for the smallest output.

Cómo usarla

  1. Paste the Markdown table.

  2. Optionally choose compact output or force an alignment.

  3. Copy the formatted table into your README or docs.

Preguntas frecuentes

Does the table have to start with a pipe?

No. Tables like a|b followed by 1|2 are accepted and written back with outer pipes.

Can it convert from Excel?

Use the Table to Markdown converter to turn copied cells into a Markdown table first.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
