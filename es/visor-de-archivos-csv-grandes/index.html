Cómo funciona Visor de archivos CSV grandes

Excel stops at about one million rows and text editors freeze on files of this size. This viewer opens CSV files of hundreds of megabytes in seconds: a table you can scroll through, a search across all columns and a "go to row" box. The file never leaves your computer.

The trick is that the file is never loaded into memory. A Web Worker (a background thread) streams through the file once and records the byte position where each row starts, taking quoted line breaks into account. Only that index is kept. When you scroll, the worker reads just the few hundred rows you are looking at from the file on disk, parses them and sends them to the table. The table itself is virtualised: only about 30 rows exist in the page at any moment, and the scrollbar is scaled so that even tens of millions of rows stay reachable. Search scans the file in blocks in the background and shows the matching rows only.

Cómo usarla

  1. Drop a CSV file onto the page or choose it.

  2. Wait a moment while the rows are indexed (a progress bar shows the status).

  3. Scroll, jump to a row number or search; clear the search to see all rows again.

Preguntas frecuentes

How large a file can it open?

Files of several hundred megabytes work well; the limit is your browser, not a server. Indexing runs at roughly 100–300 MB per second on a modern computer.

Can I edit or save changes?

This tool is a viewer. Use the other CSV tools to filter, convert or merge a file after you have looked at it.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
