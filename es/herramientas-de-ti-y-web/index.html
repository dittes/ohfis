IT and web helper tools

Hashes, encoders, cron, JWT, colours, networks and web snippets. Cada herramienta funciona en tu navegador. Nada de lo que pegas o abres se sube.

Generador de sumas de comprobación (SHA-256, MD5, SHA-1) Calcula y compara hashes de archivos en tu navegador para verificar descargas. Calculadora de subredes (CIDR, máscara, rango IP) Red, difusión, hosts utilizables y división en subredes para cualquier rango IPv4. Traductor de expresiones cron Traduce programaciones cron a lenguaje sencillo y consulta las próximas ejecuciones. Referencia de códigos de estado HTTP Busca cada código de estado HTTP con una explicación sencilla y una solución. Conversor de cURL a JavaScript y Python Convierte un comando curl en código fetch y Python requests que funciona. Decodificador de cadenas User-Agent Averigua navegador, sistema operativo, dispositivo y motor a partir de una cadena user-agent. Codificador y decodificador de entidades HTML Convierte caracteres especiales en entidades HTML y viceversa. Codificador y decodificador Base64 (texto y archivos) Codifica o decodifica Base64 y URL de datos, para texto y para archivos. Conversor de colores (HEX, RGB, HSL, CMYK) Convierte colores entre HEX, RGB, HSL, HSV y CMYK, con selector y cuentagotas. Generador de UUID / GUID (v4 y v7) Genera lotes de UUID aleatorios seguros, incluido el v7 ordenable por tiempo. Conversor de bases numéricas (binario, octal, decimal, hex) Convierte enteros entre las bases 2 a 36, de cualquier tamaño. Generador de cabecera Basic Auth Crea la cabecera Authorization: Basic a partir de un usuario y una contraseña. Calculadora de alfa hexadecimal (opacidad a hex) Convierte porcentajes de opacidad en valores alfa hexadecimales de dos dígitos, como 50 % = 80. Generador de etiqueta meta viewport Crea una etiqueta viewport correcta para páginas adaptables. Generador de etiquetas HTML de favicon Genera las etiquetas link y el manifiesto para iconos de escritorio y móvil. Constructor de cadenas de consulta de URL Convierte pares clave-valor en una cadena de consulta de URL correctamente codificada. Generador de URL anticaché Añade un parámetro de versión o marca de tiempo para que los navegadores descarguen el archivo más reciente. Comprobador de caducidad de certificados SSL y recordatorio Lee un certificado, mira cuántos días quedan y descarga recordatorios de calendario. Analizador de cabeceras de correo Rastrea la ruta de un correo, los retrasos y los resultados de SPF, DKIM y DMARC. Generador y validador de robots.txt Crea un robots.txt o comprueba uno existente en busca de errores de sintaxis. Validador y formateador de Sitemap XML Valida un sitemap según el estándar y dale formato legible. Vista previa de Open Graph y redes sociales Previsualiza cómo se ve un enlace en Facebook, X, LinkedIn y Slack y obtén las metaetiquetas. Generador de sombras CSS (box-shadow) Diseña sombras en capas de forma visual y copia CSS limpio. Explicador y probador de expresiones regulares Divide una expresión regular en partes en lenguaje sencillo y pruébala en vivo. Búsqueda de números de puerto (puertos TCP/UDP comunes) Encuentra qué servicio usa un puerto y qué puerto usa un servicio. Búsqueda de tipos MIME (extensión de archivo a Content-Type) Encuentra el Content-Type correcto para una extensión de archivo, o la extensión de un tipo MIME. Generador de registros SPF y DMARC Crea los registros TXT de DNS que impiden que otros suplanten el correo de tu dominio. Zona de pruebas y chuleta de CSS Flexbox Recorre los ajustes de flexbox, mira el resultado en vivo y copia el CSS. Probador de firmas de webhook (HMAC SHA-256) Calcula firmas de webhook al estilo GitHub, Stripe y Slack y comprueba la que recibiste. Conversor de fuentes (TTF/OTF a WOFF y viceversa) Convierte un archivo de fuente a WOFF para sitios web, o desempaqueta WOFF a TTF/OTF. Formateador y validador de JSON Formatea, minimiza, ordena y valida JSON, con la posición exacta del error. Conversor de JSON, YAML y XML Convierte entre JSON, YAML y XML en cualquier dirección. Formateador y embellecedor de SQL Haz legibles las consultas SQL con sangrías y saltos de línea. Probador de regex (JavaScript) Prueba una expresión regular en vivo: coincidencias, grupos y reemplazo. Vista previa de Markdown (en vivo) Mira el Markdown renderizado mientras escribes y copia el HTML. Minimizador de CSS, HTML y JSON Quita comentarios y espacios en blanco para hacer más pequeño el CSS, el HTML o el JSON. Generador de Lorem Ipsum Genera texto de relleno por párrafos, frases o palabras. Detector de tipo de archivo (identifica cualquier archivo) Averigua qué es realmente un archivo, por su contenido y no por su nombre. Generador de árbol de carpetas (estructura de directorios como texto) Convierte una carpeta o una lista de rutas en un árbol de texto para documentación.

Preguntas frecuentes

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
