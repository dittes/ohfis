Cómo funciona Zona de pruebas y chuleta de CSS Flexbox

Change flex-direction, justify-content, align-items, flex-wrap, align-content, gap and the number of items and watch the boxes rearrange immediately. The matching CSS is shown below and can be copied.

The main axis is the direction of the flex-direction (horizontal for row, vertical for column); justify-content distributes items along it, align-items positions them across it, and align-content only matters when wrapping creates more than one line. Items have varied heights so that the effect of align-items (stretch, center, baseline …) is visible. The playground uses the browser's real layout engine, so it always shows the true behaviour of your browser. It covers the container properties; item properties such as flex-grow, flex-shrink and flex-basis are described on MDN.

Cómo usarla

  1. Change the container properties.

  2. Watch the boxes move.

  3. Copy the CSS.

Preguntas frecuentes

What is the difference between justify-content and align-items?

justify-content works along the main axis, align-items across it. Changing flex-direction swaps which is horizontal.

Why does align-content do nothing?

It needs flex-wrap: wrap and enough items to create several lines.
