Cómo funciona Restaurar ceros a la izquierda en CSV

Excel treats 01234 as the number 1234 and silently removes the zero. Zip codes, product numbers, employee IDs and phone prefixes are damaged this way every day. This tool restores them: it detects the intended width of each column or pads to a width you choose.

For every column it looks at all values that consist only of digits. If most of them share the same maximum length and some are shorter, the shorter ones lost their zeros, and the tool pads them back to that length. You can override the width (for example 5 for US zip codes or 8 for an ID) and choose which columns to repair. After downloading, import the file with Data → From Text/CSV and set the column type to "Text"; otherwise Excel will remove the zeros again when you open it.

Cómo usarla

  1. Paste the damaged CSV or open the file.

  2. Leave the width on 0 to detect it, or enter the number of digits. Pick the columns.

  3. Download the repaired file and import it with the column set to Text.

Preguntas frecuentes

Why does Excel remove leading zeros?

Excel converts anything that looks like a number into a number, and numbers have no leading zeros. Formatting the column as Text before typing or importing prevents this.

Can it be wrong?

Detection is a guess based on the longest values in each column. Check the result, and set the width manually if a column is mixed.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
