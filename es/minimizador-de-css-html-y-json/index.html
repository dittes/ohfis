Cómo funciona Minimizador de CSS, HTML y JSON

Paste CSS, HTML or JSON and get a compact version without comments and unnecessary whitespace, with the size before and after. CSS also loses redundant semicolons and zero units and gets short hex colours; HTML keeps the content of pre, textarea, script and style blocks intact.

This is a safe, conservative minifier: it removes only what does not change how the code works, and keeps strings, pre-formatted text and conditional comments. It does not rename anything or rewrite JavaScript; for that use a build tool. Always test the result, especially HTML with inline spacing between tags.

Cómo usarla

  1. Paste the code.

  2. Check the detected type (or choose it).

  3. Copy the minified result and compare the sizes.

Preguntas frecuentes

Does it minify JavaScript?

No. Safe JavaScript minification needs a full parser; use a build tool such as esbuild or terser.

Can minifying HTML break a page?

Rarely: whitespace between inline elements can matter. The tool keeps single spaces between inline content; test the page.

¿Se suben mis archivos?

No. El archivo lo abre y procesa tu propio navegador. Puedes comprobarlo tú mismo: abre la pestaña de red de tu navegador mientras usas la herramienta, o desconéctate de internet después de cargar la página.

¿Es gratis esta herramienta?

Sí, por completo. No hay registro, ni plan de pago, ni marca de agua en tus archivos.
