Pomocné nástroje pro IT a web

Hashe, kodéry, cron, JWT, barvy, sítě a webové úryvky. Každý nástroj běží v prohlížeči. Nic, co vložíte nebo otevřete, se nenahrává.

Generátor kontrolních součtů souborů (SHA-256, MD5, SHA-1) Spočítejte a porovnejte hashe souborů v prohlížeči a ověřte stažené soubory. Kalkulačka podsítí (CIDR, maska, rozsah IP) Síť, broadcast, použitelné hostitele a dělení na podsítě pro libovolný rozsah IPv4. Překladač výrazů cron Přeložte plány cron do srozumitelného jazyka a zobrazte příští spuštění. Přehled stavových kódů HTTP Vyhledejte každý stavový kód HTTP s jednoduchým vysvětlením a řešením. Převodník cURL na JavaScript a Python Převeďte příkaz curl na funkční kód fetch a Python requests. Dekodér řetězce User-Agent Zjistěte prohlížeč, systém, zařízení a engine z řetězce user-agent. Kodér a dekodér HTML entit Převádějte speciální znaky na HTML entity a zpět. Kodér a dekodér Base64 (text a soubory) Kódujte a dekódujte Base64 a data URL, pro text i soubory. Převodník barev (HEX, RGB, HSL, CMYK) Převádějte barvy mezi HEX, RGB, HSL, HSV a CMYK s výběrem a pipetou. Generátor UUID / GUID (v4 a v7) Generujte dávky bezpečných náhodných UUID včetně časově řaditelných v7. Převodník číselných soustav (binární, osmičková, desítková, hex) Převádějte celá čísla mezi soustavami 2 až 36 libovolné velikosti. Generátor hlavičky Basic Auth Vytvořte hlavičku Authorization: Basic z uživatelského jména a hesla. Kalkulačka průhlednosti hex (krytí na hex) Převeďte procenta krytí na dvoumístné hex hodnoty alfa, např. 50 % = 80. Generátor značky meta viewport Vytvořte správnou značku viewport pro responzivní stránky. Generátor HTML značek favicony Vygenerujte značky link a manifest pro ikony na počítači i mobilu. Tvůrce parametrů URL (query string) Převeďte páry klíč-hodnota na správně zakódovaný řetězec dotazu URL. Generátor URL pro obejití cache Připojte parametr verze nebo časové razítko, aby prohlížeče načetly nejnovější soubor. Kontrola vypršení certifikátu SSL a připomenutí Přečtěte certifikát, zjistěte kolik dní zbývá a stáhněte si připomenutí do kalendáře. Analyzátor hlaviček e-mailu Sledujte cestu e-mailu, zpoždění a výsledky SPF, DKIM a DMARC. Generátor a validátor robots.txt Vytvořte robots.txt nebo zkontrolujte existující na chyby syntaxe. Validátor a formátovač sitemap XML Zvalidujte sitemapu podle standardu a naformátujte ji. Náhled Open Graph a sdílení Zobrazte náhled odkazu na Facebooku, X, LinkedInu a Slacku a získejte značky meta. Generátor CSS box-shadow Navrhujte vrstvené stíny vizuálně a kopírujte čisté CSS. Vysvětlení a testování regulárních výrazů Rozložte regulární výraz na srozumitelné části a testujte ho živě. Vyhledávání čísel portů (TCP/UDP) Zjistěte, jakou službu port používá a jaký port služba má. Vyhledávání typů MIME (přípona na Content-Type) Najděte správný Content-Type pro příponu souboru nebo příponu pro typ MIME. Generátor záznamů SPF a DMARC Vytvořte záznamy TXT v DNS, které chrání e-maily vaší domény před podvržením. CSS Flexbox hřiště a tahák Proklikejte nastavení flexboxu, uvidíte výsledek živě a zkopírujte CSS. Test podpisu webhooku (HMAC SHA-256) Vypočítejte podpisy webhooků ve stylu GitHub, Stripe a Slack a zkontrolujte přijatý. Převodník písem (TTF/OTF na WOFF a zpět) Převeďte soubor písma na WOFF pro weby, nebo rozbalte WOFF na TTF/OTF. Formátování a kontrola JSON Formátujte, minimalizujte, řaďte a kontrolujte JSON s přesnou polohou chyby. Převodník JSON, YAML a XML Převádějte mezi JSON, YAML a XML v obou směrech. Formátování SQL Zpřehledněte dotazy SQL odsazením a zalomením řádků. Tester regulárních výrazů (JavaScript) Testujte regulární výraz naživo: shody, skupiny a nahrazení. Náhled Markdownu (živě) Sledujte vykreslený Markdown při psaní a zkopírujte HTML. Minifikace CSS, HTML a JSON Odstraňte komentáře a mezery a zmenšete CSS, HTML nebo JSON. Generátor Lorem Ipsum Generujte výplňový text po odstavcích, větách nebo slovech. Rozpoznání typu souboru Zjistěte, čím soubor skutečně je, podle obsahu, ne podle názvu. Generátor stromu složek (struktura jako text) Změňte složku nebo seznam cest na textový strom pro dokumentaci.

Časté dotazy

Nahrávají se moje soubory?

Ne. Soubor otevírá a zpracovává váš vlastní prohlížeč. Můžete si to ověřit: při práci otevřete v prohlížeči kartu Síť nebo se po načtení stránky odpojte od internetu.

Je tento nástroj zdarma?

Ano, zcela. Není potřeba registrace, neexistuje placená verze a na souborech není vodoznak.

Soukromí Tiráž Běží ve vašem prohlížeči. Bez nahrávání, bez účtu, bez sledování.
