Jak funguje: Dekodér řetězce User-Agent

Vložte řetězec user-agent z logu nebo tiketu a uvidíte prohlížeč a verzi, operační systém, typ zařízení, vykreslovací jádro a zda jde o bota. Váš vlastní user agent je předvyplněn.

Parser používá seřazená pravidla, protože se user agenty navzájem napodobují: každý prohlížeč založený na Chrome říká „Mozilla“ a „Safari“, Edge přidává „Edg/“, Opera „OPR/“ a Chrome na iPhonu „CriOS“. Proto nejdřív kontroluje nejspecifičtější tokeny, pak systém (Windows NT 10.0 se hlásí jako „10 / 11“, protože ho používají oba), třídu zařízení (mobil, tablet, TV, bot) a model Androidu. Boti se rozpoznají podle běžných tokenů crawlerů. Řetězce user-agent lze padělat a Chrome jejich detaily postupně zamrazuje, takže je používejte k diagnostice, ne k rozhodování o bezpečnosti nebo funkcích.

Jak to použít

  1. Vložte řetězec user-agent (nebo použijte svůj).

  2. Přečtěte si rozpoznaný prohlížeč, systém a zařízení.

  3. Výsledky pro boty berte opatrně: řetězce lze padělat.

Časté dotazy

Proč každý prohlížeč říká Mozilla?

Z historické kompatibility: rané weby servírovaly Mozille lepší stránky, takže se tak každý prohlížeč označoval.

Proč se Windows 11 zobrazuje jako Windows 10?

Oba hlásí NT 10.0 v user agentu. Windows 11 lze odlišit jen přes client hints.

Nahrávají se moje soubory?

Ne. Soubor otevírá a zpracovává váš vlastní prohlížeč. Můžete si to ověřit: při práci otevřete v prohlížeči kartu Síť nebo se po načtení stránky odpojte od internetu.

Je tento nástroj zdarma?

Ano, zcela. Není potřeba registrace, neexistuje placená verze a na souborech není vodoznak.
