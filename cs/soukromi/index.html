Zásady ochrany soukromí

OHFIS běží ve vašem prohlížeči. Vaše soubory se nenahrávají a nepoužíváme analytiku, sledování ani cookies.

Co se děje s vašimi soubory

Soubory, které otevřete, se zpracovávají v paměti prohlížeče ve vašem zařízení. Nikdy se neodesílají nám ani nikomu jinému. Neprovozujeme server, který by soubory zpracovával.

PDF nástroje, domovská stránka a přehled PDF nástrojů navíc obsahují politiku Content Security Policy, která prohlížeči nařizuje blokovat síťová připojení k jiným serverům. Veškerý kód a data, které tyto nástroje potřebují, včetně rozpoznávání textu, pocházejí přímo z ohfis.com.

Co se ukládá ve vašem zařízení

  • Local storage: vybraný vzhled a jazyk a nastavení zobrazení.
  • IndexedDB: soubor předávaný z jednoho PDF nástroje do dalšího. Smaže se, jakmile ho další nástroj otevře.
  • Cache storage: soubory samotné aplikace, aby fungovala offline.

To vše můžete kdykoli odstranit v nastavení prohlížeče, v datech tohoto webu. Nemáme k nim žádný přístup.

Hosting

Tento web je hostován na GitHub Pages. Při návštěvě GitHub zpracovává technické údaje, jako je vaše IP adresa, aby mohl stránky doručit. Viz prohlášení GitHub o ochraně soukromí. Právním základem je náš oprávněný zájem na provozu webu (čl. 6 odst. 1 písm. f GDPR).

Vaše práva

Podle GDPR máte právo na přístup, opravu, výmaz, omezení zpracování, přenositelnost údajů a námitku a také právo podat stížnost u dozorového úřadu. Protože sami osobní údaje neshromažďujeme, obvykle o vás nemáme žádné záznamy. Dotazy rádi zodpovíme na ohfis@dittes.info.
