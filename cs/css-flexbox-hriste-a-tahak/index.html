Jak funguje: CSS Flexbox hřiště a tahák

Měňte flex-direction, justify-content, align-items, flex-wrap, align-content, gap a počet položek a sledujte, jak se boxy okamžitě přeskupí. Odpovídající CSS je zobrazeno níže a lze ho zkopírovat.

Hlavní osa je směr flex-direction (vodorovná pro row, svislá pro column); justify-content rozděluje položky podél ní, align-items je umisťuje napříč a align-content má smysl, jen když zalamování vytvoří více než jeden řádek. Položky mají různé výšky, aby byl vidět účinek align-items (stretch, center, baseline …). Hřiště používá skutečný layoutový engine prohlížeče, takže vždy ukazuje skutečné chování vašeho prohlížeče. Pokrývá vlastnosti kontejneru; vlastnosti položek jako flex-grow, flex-shrink a flex-basis jsou popsány na MDN.

Jak to použít

  1. Změňte vlastnosti kontejneru.

  2. Sledujte, jak se boxy pohybují.

  3. Zkopírujte CSS.

Časté dotazy

Jaký je rozdíl mezi justify-content a align-items?

justify-content působí podél hlavní osy, align-items napříč. Změna flex-direction prohodí, která je vodorovná.

Proč align-content nic nedělá?

Potřebuje flex-wrap: wrap a dost položek na více řádků.

Nahrávají se moje soubory?

Ne. Soubor otevírá a zpracovává váš vlastní prohlížeč. Můžete si to ověřit: při práci otevřete v prohlížeči kartu Síť nebo se po načtení stránky odpojte od internetu.

Je tento nástroj zdarma?

Ano, zcela. Není potřeba registrace, neexistuje placená verze a na souborech není vodoznak.
