Jak funguje: Minifikace CSS, HTML a JSON

Vložte CSS, HTML nebo JSON a získáte kompaktní verzi bez komentářů a zbytečných mezer, s velikostí před a po. CSS navíc ztratí nadbytečné středníky a jednotky u nuly a získá krátké hexadecimální barvy; HTML ponechá obsah bloků pre, textarea, script a style beze změny.

Je to bezpečný, opatrný minifikátor: odstraní jen to, co nemění fungování kódu, a ponechá řetězce, předformátovaný text a podmíněné komentáře. Nic nepřejmenovává a nepřepisuje JavaScript; k tomu použijte build nástroj. Výsledek vždy otestujte, zejména u HTML s mezerami mezi řádkovými značkami.

Jak to použít

  1. Vložte kód.

  2. Zkontrolujte rozpoznaný typ (nebo ho zvolte).

  3. Zkopírujte minifikovaný výsledek a porovnejte velikosti.

Časté dotazy

Minifikuje JavaScript?

Ne. Bezpečná minifikace JavaScriptu potřebuje úplný parser; použijte build nástroj jako esbuild nebo terser.

Může minifikace HTML rozbít stránku?

Zřídka: mezery mezi řádkovými prvky mohou hrát roli. Nástroj ponechává jednotlivé mezery mezi řádkovým obsahem; stránku otestujte.

Nahrávají se moje soubory?

Ne. Soubor otevírá a zpracovává váš vlastní prohlížeč. Můžete si to ověřit: při práci otevřete v prohlížeči kartu Síť nebo se po načtení stránky odpojte od internetu.

Je tento nástroj zdarma?

Ano, zcela. Není potřeba registrace, neexistuje placená verze a na souborech není vodoznak.

Mohlo by se vám hodit

Formátování a kontrola JSON Formátujte, minimalizujte, řaďte a kontrolujte JSON s přesnou polohou chyby. Optimalizátor a minifikátor SVG Zmenšete soubory SVG odstraněním zbytečností z editoru a zaokrouhlením čísel, s náhledem. Komprese obrázků (zmenšení velikosti fotek) Zmenšete soubory JPG, PNG a WebP s nastavitelnou kvalitou a uvidíte úsporu.
