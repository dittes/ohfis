How robots.txt Generator & Validator works

Control which parts of your site crawlers may visit. Build a file from a list of blocked paths, exceptions and your sitemap URL, with an option to block AI-training crawlers, or paste an existing file and see every problem with its line number.

The validator checks each line against the robots.txt syntax (RFC 9309): field names, that rules belong to a User-agent group, that paths start with / or *, that Sitemap is an absolute URL and that crawl-delay is a number. It warns about directives search engines ignore (noindex, which Google no longer supports), and about "Disallow: /" for all agents, which blocks the whole site. robots.txt is a request, not access control: well-behaved crawlers follow it, but it does not hide pages, and blocked pages can still appear in search results if linked elsewhere.

How to use it

  1. Choose "Check" or "Build".

  2. Paste your file, or enter the paths and sitemap URL.

  3. Fix the listed problems, or copy and upload the new file to your site's root.

Frequently asked questions

Does Disallow remove a page from Google?

No. It only stops crawling. To keep a page out of search results use a noindex meta tag or password protection.

Where must robots.txt be placed?

At the root of the host: https://example.com/robots.txt.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
