How Screen Refresh Rate & Frame Drop Test works

Is your 144 Hz monitor really running at 144 Hz in the browser? Press measure, watch the moving bar for five seconds and get the measured refresh rate, the nearest standard rate, the average frame time, the jitter (standard deviation of frame times) and the number of slow frames, with advice if the animation is uneven.

The page counts requestAnimationFrame callbacks, which browsers fire once per display refresh, and analyses the intervals between them: refresh rate = 1000 ÷ average interval in ms. A frame counts as slow if it took more than 1.5 times the expected interval for the nearest common rate (24–240 Hz). Browsers can cap animation below the monitor's real rate (power saving, background tabs, variable refresh rate), so this measures what web pages actually get. It does not measure input lag or response time, which need a camera or hardware tester.

How to use it

  1. Close heavy tabs and press "Measure for 5 seconds".

  2. Watch the bar for stutter.

  3. Compare the Hz with your monitor settings.

Frequently asked questions

Why does it show 60 Hz on my 144 Hz monitor?

The operating system may be set to 60 Hz, a power-saving mode may be on, or the browser window is on a different screen.

What is a good jitter value?

Below about 1.5 ms on a 60 Hz display means an even animation.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
