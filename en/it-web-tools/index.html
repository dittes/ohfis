IT and web helper tools

Hashes, encoders, cron, JWT, colours, networks and web snippets. Every tool runs in your browser. Nothing you paste or open is uploaded.

File Checksum Generator (SHA-256, MD5, SHA-1) Calculate and compare file hashes in your browser to verify downloads. Subnet Calculator (CIDR, Netmask, IP Range) Network, broadcast, usable hosts and subnet splitting for any IPv4 range. Cron Expression Translator Translate cron schedules into plain English and see the next run times. HTTP Status Codes Reference Search every HTTP status code with a plain explanation and a fix. cURL to JavaScript & Python Converter Turn a curl command into working fetch and Python requests code. User-Agent String Decoder Find out browser, OS, device and engine from a user-agent string. HTML Entity Encoder & Decoder Convert special characters to HTML entities and back. Base64 Encoder & Decoder (Text and Files) Encode or decode Base64 and data URLs, for text and for files. Color Converter (HEX, RGB, HSL, CMYK) Convert colours between HEX, RGB, HSL, HSV and CMYK, with picker and eyedropper. UUID / GUID Generator (v4 & v7) Generate batches of secure random UUIDs, including time-sortable v7. Number Base Converter (Binary, Octal, Decimal, Hex) Convert integers between bases 2 to 36, with arbitrary size. Basic Auth Header Generator Create the Authorization: Basic header from a username and password. Hex Color Alpha (Opacity to Hex) Calculator Convert opacity percentages to two-digit hex alpha values like 50% = 80. Meta Viewport Tag Generator Build a correct viewport tag for responsive pages. Favicon HTML Tag Generator Generate the link tags and manifest for desktop and mobile icons. URL Query String Builder Turn key-value pairs into a correctly percent-encoded URL query string. Cache Buster URL Generator Append a version or timestamp parameter so browsers fetch the latest file. SSL Certificate Expiry Checker & Reminder Read a certificate, see how many days remain and download calendar reminders. Email Header Analyzer Trace an email's route, delays and SPF, DKIM and DMARC results. robots.txt Generator & Validator Build a robots.txt or check an existing one for syntax mistakes. Sitemap XML Validator & Formatter Validate a sitemap against the standard and pretty-print it. Open Graph & Social Share Preview Preview how a link looks on Facebook, X, LinkedIn and Slack and get the meta tags. CSS Box Shadow Generator Design layered box shadows visually and copy clean CSS. Regular Expression Explainer & Tester Break a regular expression into plain-language parts and test it live. Port Number Lookup (Common TCP/UDP Ports) Find which service uses a port, and which port a service uses. MIME Type Lookup (File Extension to Content-Type) Find the correct Content-Type for a file extension, or the extension for a MIME type. SPF & DMARC Record Generator Build the DNS TXT records that stop others from spoofing your domain's email. CSS Flexbox Playground & Cheat Sheet Click through flexbox settings, see the result live and copy the CSS. Webhook Signature Tester (HMAC SHA-256) Calculate GitHub, Stripe and Slack style webhook signatures and check the one you received.

Frequently asked questions

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.

Privacy Imprint Runs in your browser. No upload, no account, no tracking.
