How File Type Detector (Identify Any File) works

Drop a file with no extension, a strange extension or a name you do not trust and see what it really is: image, PDF, Office document, archive, audio, video, font, executable, database or text. For each file you get the detected type, the MIME type and whether the file name matches the content.

The type is read from the first bytes of the file (its "magic number"), the way the Unix file command does, so it does not depend on the name. ZIP-based formats are told apart by their entries (DOCX, XLSX, PPTX, EPUB, JAR, APK, OpenDocument), MP4-family files by their brand (MP4, MOV, HEIC, AVIF) and text files by their content (JSON, HTML, XML, SVG, scripts). About 60 common formats are recognised; a file that matches none is reported as unknown binary data. A mismatch between name and content is a warning sign for malware, but also happens innocently.

How to use it

  1. Drop one or more files.

  2. Read the detected type and whether the name matches.

  3. Rename the file with the right extension if needed.

Frequently asked questions

Is a mismatch dangerous?

It can be: malware often hides behind a harmless extension. It is also common after a wrong rename. Do not open files you do not trust.

Is the file uploaded?

No. Only the first 70 KB are read in your browser.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
