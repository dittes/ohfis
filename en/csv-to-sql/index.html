CSV to SQL INSERT Converter

Turn spreadsheet rows into INSERT or UPDATE statements for MySQL, PostgreSQL, SQLite or SQL Server.

How CSV to SQL INSERT Converter works

Paste rows from a spreadsheet and get SQL you can run: a CREATE TABLE with guessed column types, batched INSERT statements or one UPDATE per row using a key column. Quoting of table and column names follows the database you choose (backticks, double quotes or brackets).

Column types are inferred from the data: integers, decimals, booleans, dates, timestamps, otherwise text; columns with leading zeros stay text so zip codes survive. Strings are escaped by doubling single quotes (and backslashes for MySQL), empty cells can become NULL and SQL Server strings get the N prefix for Unicode. INSERTs are split into batches of the size you set. Always review generated SQL before running it against a production database.

How to use it

  1. Paste your CSV and enter the table name.

  2. Choose the database, INSERT or UPDATE, and whether to create the table.

  3. Copy the SQL or download the .sql file.

Frequently asked questions

Is the SQL safe against injection?

Values are escaped, but the output is meant for import scripts you control. Never paste untrusted data into a script you run unreviewed.

How are types chosen?

From the values in each column. Check the CREATE TABLE and adjust types such as DECIMAL precision for your needs.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
