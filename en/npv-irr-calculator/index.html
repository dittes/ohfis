How NPV & IRR Calculator works

Evaluate a project by entering the discount rate and a list of cash flows, with the investment as a negative number first. The result is the net present value (NPV), the internal rate of return (IRR), the discounted payback time and a table of discount factors.

NPV = Σ cash flow(t) ÷ (1 + r)^t, with the first flow at t = 0 (not discounted). IRR is the rate at which NPV is zero, found by bisection to high precision; it is reported as "no solution" if the flows never change sign. Discounted payback interpolates the point at which the cumulative present value turns positive. Note that Excel's NPV function discounts the first value by one period, so add the initial investment outside the function.

How to use it

  1. Enter the discount rate.

  2. List the cash flows, one per period, investment first.

  3. Read NPV, IRR and payback.

Frequently asked questions

What does a positive NPV mean?

The project earns more than your required return, so it adds value.

Why does Excel give a different NPV?

Excel treats the first value as period 1. This calculator treats it as today, as in most textbooks.
