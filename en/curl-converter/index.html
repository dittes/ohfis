How cURL to JavaScript & Python Converter works

API docs and browser dev tools give you curl commands. Paste one and get equivalent JavaScript fetch code and Python requests code with the same method, headers, body, basic auth and form fields.

The command is split into words following shell quoting rules (single and double quotes, backslash line continuations, $'…' strings), and the options are interpreted: -X, -H, -d / --data-raw / --data-binary, --json, -u, -F, -A, -e, -b, -k, -L and more, with options that do not change the request (-s, -v, -o, --compressed) ignored. JSON bodies are recognised and generated as JSON.stringify(...) or a Python dict (true/false/null become True/False/None); basic auth becomes an Authorization header or the auth= argument. Check generated code before running it: secrets in the command end up in your code.

How to use it

  1. Paste a curl command (in the browser: Network tab → right-click a request → Copy as cURL).

  2. Read the generated JavaScript and Python.

  3. Copy the code you need.

Frequently asked questions

Which curl options are supported?

Method, headers, data, JSON, auth, forms, user agent, referer, cookies, redirects and insecure mode. Unsupported options that affect the output are reported where possible.

Is my command sent anywhere?

No. The conversion runs in your browser, which matters because curl commands often contain tokens.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
