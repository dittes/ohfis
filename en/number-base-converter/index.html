How Number Base Converter (Binary, Octal, Decimal, Hex) works

Enter a number in any base from 2 to 36 and see it in binary, octal, decimal, hexadecimal and one more base of your choice. Prefixes such as 0x and 0b and underscores are understood, and numbers can be of any size, because the tool uses arbitrary-precision integers instead of floating point.

The input is read digit by digit in the chosen base into a BigInt, so values beyond 2^53 are exact (where JavaScript's normal numbers would lose digits), and then written in each target base with toString(base). Invalid digits are named in the error message. The bit count shows how many binary digits the number needs, which tells you whether it fits into 8, 16, 32 or 64 bits.

How to use it

  1. Enter the number and choose its base.

  3. Copy the value you need.

Frequently asked questions

How do I convert hex to decimal?

Each hex digit is worth 16 times the one to its right: FF = 15×16 + 15 = 255.

What is the largest number it can handle?

There is no fixed limit; memory is the only constraint.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
