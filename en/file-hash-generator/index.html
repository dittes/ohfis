How File Checksum Generator (SHA-256, MD5, SHA-1) works

Download pages publish a checksum so you can check that the file is exactly what the publisher built. Drop the file here, paste the published value and you immediately see whether they match. SHA-256, SHA-384, SHA-512, SHA-1 and MD5 can be calculated at once, for files or for typed text.

SHA-1, SHA-256, SHA-384 and SHA-512 use the browser's Web Crypto API (native code). MD5 is not part of Web Crypto, so it is implemented here as an incremental algorithm that reads the file in 8 MB pieces and updates the hash piece by piece, showing progress. Results are verified against the published test vectors of each algorithm. MD5 and SHA-1 are broken for security purposes (collisions can be created), so use SHA-256 to verify downloads against tampering; MD5 remains fine for spotting accidental corruption.

How to use it

  1. Drop a file (or type text) and choose the algorithms.

  2. Optionally paste the checksum from the download page into the compare field.

  3. Read the green or red result and copy the hash you need.

Frequently asked questions

Is my file uploaded?

No. The file is read and hashed on your device. The page makes no network request with your data.

Which hash should I use?

SHA-256 to verify downloads. MD5 and SHA-1 only to detect accidental changes, because they are not collision-resistant.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
