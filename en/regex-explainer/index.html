How Regular Expression Explainer & Tester works

Paste a regular expression and see it explained token by token in nested form: what each group, class, quantifier and anchor means. A test area highlights the matches line by line, so you can see whether it does what you think.

The expression is parsed by a small recursive reader that understands groups (capturing, non-capturing, named, lookahead and lookbehind), alternation, character classes, escapes such as \d \w \s \b, back-references and quantifiers (* + ? {n,m}, including lazy versions) and prints each part with its meaning, indented by nesting depth. Testing uses your browser's own JavaScript RegExp engine, so results match what your code will do. Syntax errors are reported with the engine's message.

How to use it

  1. Paste your regular expression and set flags.

  2. Read the explanation of each part.

  3. Edit the test text to check matches and non-matches.

Frequently asked questions

Which regex flavour is explained?

JavaScript (ECMAScript). Most syntax is shared with PCRE, Python and Java, but details such as lookbehind and named groups differ.

What does the g flag do?

It finds all matches instead of stopping at the first one; the tester always shows all matches.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
