How CSV Header Cleaner (snake_case) works

Headers like "First Name", "Revenue (€)" or "2024 Sales" break imports into SQL, pandas and BI tools. This tool rewrites them as lowercase snake_case (or camelCase or kebab-case): accents are removed, symbols are spelled out (% → pct), names that start with a digit get a prefix, duplicates are numbered and SQL keywords are made safe.

Each header is normalised with Unicode decomposition to strip accents, split into words at spaces, punctuation and camelCase boundaries, lower-cased and joined with the chosen separator. Empty headers become column_N, duplicates get _2, _3 and so on, and words that clash with common SQL keywords receive a _col suffix. The summary lists every rename so you can map columns back.

How to use it

  1. Paste the CSV with the messy header row.

  2. Choose snake_case, camelCase or kebab-case and an optional maximum length.

  3. Copy or download the table with the clean header.

Frequently asked questions

Does it change my data?

Only the first row (the header) is changed.

Why add _col to "user"?

Words such as user, order, group or index are reserved in many SQL dialects and need quoting; a suffix avoids that problem.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
