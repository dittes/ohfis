How MIME Type Lookup (File Extension to Content-Type) works

Which Content-Type should a server send for a .docx, a .webp or a .wasm file? Search by extension, file name or by MIME type and get the registered value, including the long names of Office formats.

A MIME type (media type) has the form type/subtype, for example image/png, and tells browsers how to handle a response. Text types normally add a charset, e.g. text/html; charset=utf-8. If the type is wrong, browsers may download instead of displaying a file, refuse to run a script (module scripts need a JavaScript type) or reject a font. For unknown binary data the safe default is application/octet-stream. The list covers common web, document, image, audio, video, archive and font formats.

How to use it

  1. Type an extension such as .docx or a MIME type such as image/png.

  2. Copy the matching Content-Type.

  3. Configure your server or upload accordingly.

Frequently asked questions

What is the MIME type of a .docx file?

application/vnd.openxmlformats-officedocument.wordprocessingml.document.

What should I use if I do not know the type?

application/octet-stream, which tells the browser it is generic binary data.
