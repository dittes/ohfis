How Excel Custom Number Format Tester works

Custom formats in Excel are powerful and cryptic. Type a format code, paste test values and see exactly how each one will be displayed: thousands separators, decimals, percentages, scientific notation, dates and times, text, colours and up to four sections for positive, negative, zero and text values. Sixteen presets show common patterns such as accounting, K/M suffixes and leading zeros.

The tester implements the rules from the Office format specification: placeholders 0 (always a digit), # (digit if needed) and ? (space-padded digit), the thousands separator and the scaling comma (a trailing comma divides by 1,000), percent scaling, E+ exponents, quoted literals, _ and * spacing, [>100] conditions, and date tokens where m means minutes next to h or s and months otherwise. Colour codes are accepted but not displayed, and fractions (# ?/?) are not supported.

How to use it

  1. Pick a preset or type your own format code.

  2. Edit the test values, one per line.

  3. Read the preview and copy the code into Format Cells → Custom.

Frequently asked questions

What does the comma at the end of a format do?

Each trailing comma divides the number by 1,000, so #,##0, shows 1234567 as 1,235 and 0.0,, shows it in millions.

How do I show numbers over a million as M and others as K?

Use conditions: [>=1000000]0.0,,"M";[>=1000]0.0,"K";0
