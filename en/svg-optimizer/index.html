How SVG Optimizer & Minifier works

Paste SVG code or open a .svg file exported from Illustrator, Inkscape or Figma and get a smaller file: XML declaration, DOCTYPE, comments, editor metadata and namespaces are removed, numbers are rounded to the decimal places you choose and whitespace is collapsed. A live preview and the saved percentage help you check the result before you download it.

The optimiser is deliberately conservative and text based: it does not merge or rewrite paths, so the drawing cannot change shape. Typical savings are 20–60 % on files from design tools. Unused id attributes can be removed, but ids that are referenced (for gradients, clip paths or links) are always kept. The result is parsed as XML to make sure it is still valid, and shown as an image. Removing <title> and <desc> makes files smaller but removes the accessible name of the graphic, so it is off by default. For aggressive path simplification use a dedicated tool such as SVGO and compare the output.

How to use it

  1. Paste the SVG or open the file.

  2. Set the decimal places and options.

  3. Check the preview and copy or download the result.

Frequently asked questions

Will the SVG look the same?

Yes, with 2 decimals for icons and 1–2 for illustrations. Very small icons may need 3.

Why keep the viewBox?

It makes the SVG scalable. The optimiser only rounds its numbers.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
