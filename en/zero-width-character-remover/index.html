How Zero-Width Character Remover works

Text copied from websites, PDFs, chat apps and AI tools often carries characters you cannot see: zero-width spaces (U+200B), byte order marks (U+FEFF), soft hyphens, no-break spaces and directional marks. They break string comparisons, make database lookups fail and cause "mystery" errors in code, CSV files and passwords.

The tool walks through your text one Unicode character at a time and compares each one with a table of 19 invisible or look-alike characters. It deletes the invisible ones, turns no-break and exotic spaces into normal spaces, and lists exactly what it found with the Unicode code point, so you can see what was hiding in your text. Joiners that glue emoji together can be kept.

How to use it

  1. Paste the text that behaves strangely.

  2. Choose whether no-break spaces should become normal spaces and whether emoji joiners stay.

  3. Copy the cleaned text. The list underneath shows which hidden characters were removed.

Frequently asked questions

How can I see hidden characters in my text?

Paste it here. Every invisible character found is listed with its Unicode code point and name, such as U+200B zero width space.

Will this break emoji?

Family and flag emoji use an invisible joiner (U+200D). Tick "Keep joiners inside emoji" to leave those intact.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
