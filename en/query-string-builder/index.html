How URL Query String Builder works

List parameters as key=value lines and get the encoded query string, optionally appended to a base URL. Spaces, ampersands, equals signs, accents and emoji are escaped correctly, and repeated keys can be written as tag=a&tag=b, tag[]=a&tag[]=b or tag=a,b.

Each key and value is encoded as UTF-8 with percent-escapes using encodeURIComponent plus the characters it leaves alone (! ' ( ) *), so the result is safe in any URL. Spaces become %20, or + if you choose the form-encoding style. Encoding the whole URL again would double-encode (%2520), so build the query string once and append it. Empty keys are skipped.

How to use it

  1. Enter parameters as key=value lines.

  2. Choose how spaces and repeated keys are written.

  3. Copy the query string or the full URL.

Frequently asked questions

%20 or + for spaces?

%20 works everywhere in URLs. + only means space in form-encoded query strings (application/x-www-form-urlencoded).

Why is & turned into %26?

Because a literal & inside a value would otherwise start a new parameter.
