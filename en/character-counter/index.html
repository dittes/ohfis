How Character Counter works

Paste a post, ad or message and see the number of characters, characters without spaces, words, sentences, lines, bytes and visible symbols. Progress bars compare your length with the limits of X (Twitter), LinkedIn, Instagram, Google Ads headlines and descriptions, page titles and meta descriptions, YouTube and TikTok.

Characters are counted by Unicode code point, so emoji are not counted twice; "visible symbols" use grapheme segmentation, which treats a family emoji as one symbol. The SMS check follows the GSM-7 rules: 160 characters per message (153 when split), characters such as € or [ count double, and a single character outside GSM-7 switches the message to Unicode with 70 (67 when split) characters. Bytes are UTF-8 bytes, useful for database columns.

How to use it

  1. Paste or type your text.

  2. Read the counts and watch the bars for each platform.

  3. Edit until every bar you care about is within its limit.

Frequently asked questions

How many characters is a tweet?

A post on X allows 280 characters for most accounts. Links count as 23 on X itself, so allow for that when your text contains URLs.

Why does my SMS count as two messages?

A single non-GSM character, like an emoji or a curly quote, turns the whole message into Unicode, which allows only 70 characters per message.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
