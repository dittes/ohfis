How SQL Formatter and Beautifier works

Paste a long one-line query and get it formatted with each clause on its own line, indented joins and conditions and keywords in upper case. Choose the dialect (standard SQL, PostgreSQL, MySQL, MariaDB, SQLite, SQL Server, Oracle, BigQuery, Snowflake), the keyword case and the indentation.

The formatter is the open-source sql-formatter library, running in your browser; your queries are not sent anywhere, which matters when they contain table names or values from a real system. It formats; it does not check that the query would run, and unusual vendor syntax can be laid out differently than you would.

How to use it

  1. Paste the SQL.

  2. Choose the dialect, keyword case and indentation.

  3. Copy the formatted query.

Frequently asked questions

Does it validate my SQL?

No. It only formats. A syntax error may show up as a formatting error, but a valid-looking query can still fail on your database.

Which dialect should I pick?

The one of your database. Standard SQL works for simple queries; vendor-specific features format best with the matching dialect.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
