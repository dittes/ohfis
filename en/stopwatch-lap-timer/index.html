How Stopwatch with Lap Times (CSV Export) works

Time a run, a process step or a speaker. Start, stop and record any number of laps with the buttons or the keyboard (Space to start and stop, L for a lap). The table shows each lap time and the cumulative time, and one click exports it as CSV for a spreadsheet.

Time comes from performance.now(), a monotonic clock with sub-millisecond resolution that is not affected by system clock changes, and the display updates on every animation frame. Stopping keeps the elapsed time so you can resume. Lap time is the difference to the previous lap and total time is measured from the start. The CSV contains both milliseconds and formatted times.

How to use it

  1. Press Start (or Space).

  2. Press Lap (or L) for every split.

  3. Stop, then export the laps as CSV if you need them elsewhere.

Frequently asked questions

How accurate is it?

Display and recording are to the millisecond. Real-world accuracy is limited by your reaction time when pressing the button.

Does it run in the background?

Yes, the elapsed time is based on a clock, not on counting frames, so switching tabs does not lose time.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
