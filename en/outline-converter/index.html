How Indented Text to JSON, HTML & XML works

Write a tree the easy way (one item per line, indented to show hierarchy) and convert it to a structured format. Typical uses: a menu structure for a website, a folder tree, an org structure or a table of contents.

The converter reads the indentation of each line (tabs count as the number of spaces you choose), optionally ignoring list markers such as "-", "*" or "1.", and builds a tree using a stack: a line that is indented deeper becomes a child of the previous line, a line at the same or a smaller depth closes the branches above it. The tree is then serialised as JSON with text and children fields, a nested HTML <ul>, XML items, a Markdown list or YAML.

How to use it

  1. Type or paste your outline, indenting children with tabs or spaces.

  2. Pick the output format.

  3. Copy the generated structure.

Frequently asked questions

How deep can the tree be?

There is no fixed limit. Each deeper indentation level creates a new level.

Does it handle mixed tabs and spaces?

Tabs are converted to the number of spaces you set, so mixed indentation works as long as the visual depth is consistent.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
