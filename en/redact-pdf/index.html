A black box alone is not redaction

Drawing a black rectangle over text in a normal editor only hides it: the text is still in the file and can be copied out, a mistake that has exposed secrets in many published documents. This tool burns the black box into the page and removes the original content.

Each page you mark is turned into an image with the boxes in place, so the text beneath no longer exists. The remaining text on that page stops being selectable, while unmarked pages stay as they were. Document properties, bookmarks and attachments are removed from the file as well, since they can give away the same details.

How to redact a PDF

  1. Choose your PDF file.

  2. Drag over everything you want to black out, on as many pages as needed.

  3. Click “Redact permanently” and download the new file, then check it before sharing.

Frequently asked questions

Can the blacked-out text be recovered?

No. The page content is replaced by an image, so the original text on marked pages no longer exists in the new file.

Why can I no longer select text on redacted pages?

Those pages become images, which is what guarantees the hidden text is gone. Run OCR PDF afterwards if you need the remaining text to be searchable.

Does it remove metadata too?

Yes. Document properties, bookmarks, form data and attachments are removed from the redacted file.

Is my original changed?

No. You download a new file, so keep your original somewhere safe and share only the redacted version.

Are my files uploaded?

No. The file is opened and processed by your own browser. You can check it yourself: open your browser's network tab while using the tool, or disconnect from the internet after the page has loaded.

Is this tool free?

Yes, completely. There is no sign-up, no paid tier and no watermark on your files.
