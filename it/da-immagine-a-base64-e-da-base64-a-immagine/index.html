Come funziona Da immagine a Base64 e da Base64 a immagine

Embed a small icon directly into HTML, CSS or an email, or look at what a long Base64 string from an API really is. Drop an image to get a data URI, a ready <img> tag, a CSS background-image rule or the bare Base64; paste Base64 below to see the picture.

The file's bytes are encoded as Base64 and prefixed with the media type to make a data URI (data:image/png;base64,…). Base64 uses 4 characters for every 3 bytes, so the text is about one third larger than the file, and inline images cannot be cached separately by the browser, so this is only worthwhile for small icons (a few KB). The reverse direction accepts a full data URI or bare Base64 and detects the image type from its first bytes.

Come si usa

  1. Drop an image and choose the output format.

  2. Copy the data URI, HTML tag or CSS.

  3. To reverse, paste Base64 into the second box.

Domande frequenti

Should I inline images as Base64?

Only small ones (under about 5 KB). Larger images are better as separate cached files.

Why is the Base64 larger than the file?

Base64 encodes 3 bytes as 4 characters, an increase of about 33%.

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
