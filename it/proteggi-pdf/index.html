Proteggi un PDF con una password

Cifra il tuo PDF in modo che solo chi ha la password possa aprirlo.

Nota: la protezione con password tiene lontani i lettori occasionali, ma non garantisce la riservatezza. Per documenti molto sensibili non affidarti solo a essa.

Vera cifratura, e solo tu conosci la password

Il tuo PDF viene cifrato con AES-256, il più forte standard che il formato PDF offre. Senza la password il suo contenuto è illeggibile, anche se il file finisce nelle mani sbagliate. Puoi anche limitare stampa, copia e modifica.

Molti strumenti online vedono la tua password oltre al tuo documento. Qui entrambi restano sul tuo dispositivo. Questo significa anche che nessuno può recuperare una password dimenticata, quindi conservala in un posto sicuro.

Come proteggere un PDF con una password

  1. Scegli il tuo file PDF.

  2. Inserisci una password due volte e scegli cosa possono fare i lettori.

  3. Clicca su «Proteggi PDF» e scarica il file cifrato.

Perché lo usano in tanti

Il tuo file non lascia mai il tuo dispositivo

Altri strumenti PDF online caricano il tuo documento sui loro server. Questo lavora dentro il tuo browser, quindi non c'è nulla da intercettare, conservare o cancellare in seguito.

Gratis, senza limiti da aggirare

Nessun account, nessun indirizzo e-mail, nessuna quota giornaliera e nessuna filigrana sul risultato. L'unico limite è ciò che il tuo dispositivo riesce a gestire.

Funziona ovunque ci sia un browser

Windows, Mac, Linux, Android e iPhone. Niente da installare e, una volta caricata, la pagina continua a funzionare senza connessione a internet.

Domande frequenti

Cosa succede se dimentico la password?

Il file non si può aprire senza di essa e nessuno può recuperarla per te. Conserva l'originale non protetto oppure custodisci la password in sicurezza.

Quanto è forte la protezione?

AES-256 è molto forte se la tua password è buona. Usane una lunga che non sia una parola comune.

Le restrizioni di stampa e copia funzionano sempre?

Le restrizioni dipendono dal fatto che il software di lettura le rispetti, e non tutti i programmi lo fanno. La password per aprire il file è la vera protezione.

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
