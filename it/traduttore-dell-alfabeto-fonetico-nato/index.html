Come funziona Traduttore dell'alfabeto fonetico NATO

When you read a licence key, booking reference or surname over the phone, "B" and "D" are easy to confuse. The NATO phonetic alphabet gives every letter a distinct word. Type any text and get the spelled-out version, with digits as words and spaces shown as a slash.

Each character is looked up in the ICAO/NATO table (Alfa, Bravo, Charlie … Zulu, plus Zero to Nine). Accented letters are reduced to their base letter first (Ä → A), and ß is spelled as two S. Lower-case letters can be shown in lower case so you can tell capitals from small letters when reading out a password.

Come si usa

  1. Type the text, code or name you need to spell.

  2. Decide whether lower-case letters should be shown in lower case.

  3. Read it out or copy it into a message.

Domande frequenti

Is it "Alfa" or "Alpha"?

The official ICAO spelling is Alfa (and Juliett), which avoids mispronunciation by non-English speakers.

Does it work for other languages?

It spells the Latin alphabet. Accented letters are reduced to their base letter.
