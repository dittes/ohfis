Informativa sulla privacy

Ohfis gira nel tuo browser. I tuoi file non vengono caricati e non usiamo analisi, tracciamento né cookie.

Cosa succede ai tuoi file

I file che apri vengono elaborati nella memoria del tuo browser, sul tuo dispositivo. Non vengono mai inviati a noi né a nessun altro. Non gestiamo alcun server che elabori file.

Gli strumenti PDF, la home page e la panoramica dei PDF contengono inoltre una Content Security Policy, che dice al tuo browser di bloccare le connessioni di rete verso altri server. Tutto il codice e tutti i dati di cui questi strumenti hanno bisogno, incluso il riconoscimento del testo, sono serviti da ohfis.com stesso.

Cosa viene memorizzato sul tuo dispositivo

  • Local storage: la tua scelta di tema e lingua, le preferenze di visualizzazione, i preferiti, gli strumenti usati di recente e le lavagne che salvi.
  • IndexedDB: un file che passi da uno strumento PDF al successivo. Viene cancellato non appena il prossimo strumento lo ha aperto.
  • Cache storage: i file dell'app stessa, perché continui a funzionare offline.

Puoi rimuovere tutto questo in qualsiasi momento dalle impostazioni del browser, tra i dati del sito di questo sito web. Non abbiamo accesso a nulla di tutto ciò.

Hosting

Questo sito web è ospitato su GitHub Pages. Quando lo visiti, GitHub elabora dati tecnici come il tuo indirizzo IP per consegnare le pagine. Vedi l'informativa sulla privacy di GitHub. La base giuridica è il nostro legittimo interesse a fornire il sito web (art. 6, par. 1, lett. f GDPR).

I tuoi diritti

Ai sensi del GDPR hai diritto di accesso, rettifica, cancellazione, limitazione, portabilità dei dati e opposizione, nonché il diritto di proporre reclamo a un'autorità di controllo. Poiché noi non raccogliamo dati personali, di norma non avremo nulla su di te. Le domande sono benvenute a ohfis@dittes.info.
