Archivio di frammenti (testi da copiare con un clic)

Conserva i testi che incolli ogni giorno e copiali con un clic.

Caricamento dello strumento…

  • Nessun upload
  • Gratis
  • Nessun account
  • Funziona offline dopo il caricamento

Come funziona Archivio di frammenti (testi da copiare con un clic)

Save the phrases you type again and again: an email signature, a canned reply, your address, a tax number, a code block, a meeting link. Search them, click Copy and paste anywhere. Snippets can be edited, deleted, exported as a JSON backup and imported again.

The snippets are stored in your browser's localStorage on this device only; the page has no account and sends nothing anywhere. That makes it fast and private, but also means they do not sync between devices, disappear if you clear site data and are readable by anyone who uses this browser profile, so do not keep passwords or other secrets here. Export a backup file from time to time, and import it on another device to move your snippets.

Come si usa

  1. Add a title and the text, then press Add snippet.

  2. Search the list and press Copy.

  3. Export a backup before clearing browser data.

Domande frequenti

Where are my snippets stored?

In this browser only (localStorage). Export a JSON file to back them up or move them.

Is it safe for passwords?

No. Use a password manager for secrets.

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
