Decodificatore e verificatore JWT

Leggi intestazione, payload e scadenza di un JSON Web Token senza inviarlo da nessuna parte.

Caricamento dello strumento…

  • Nessun upload
  • Gratis
  • Nessun account
  • Funziona offline dopo il caricamento

Come funziona Decodificatore e verificatore JWT

Paste a token and see its header and payload as formatted JSON, with the issued-at, not-before and expiry times converted to dates and a clear "expired" or "valid" status. Enter the secret to check an HS256, HS384 or HS512 signature. Warnings flag unsigned tokens (alg none) and tokens that never expire.

A JWT is three Base64URL parts separated by dots: header.payload.signature. The first two are decoded and parsed as JSON in your browser, so the token is never uploaded, which matters because tokens grant access. For HMAC algorithms the signature is recomputed with Web Crypto over "header.payload" and compared with the one in the token. Public-key algorithms (RS256, ES256) cannot be verified without the key and are not checked here. Decoding does not prove authenticity, and a JWT is only signed, not encrypted: do not put secrets into the payload.

Come si usa

  1. Paste the JWT (a leading "Bearer " is fine).

  2. Read the header, payload and time claims.

  3. Optionally enter the secret to verify an HMAC signature.

Domande frequenti

Is it safe to paste a JWT here?

The token is decoded in your browser and never sent. Still, treat tokens like passwords and avoid pasting production tokens into tools you do not trust.

Can anyone read a JWT payload?

Yes. The payload is only encoded, not encrypted. Anyone holding the token can read it.

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
