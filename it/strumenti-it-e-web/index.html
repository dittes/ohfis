IT and web helper tools

Hashes, encoders, cron, JWT, colours, networks and web snippets. Ogni strumento funziona nel tuo browser. Nulla di ciò che incolli o apri viene caricato.

Generatore di checksum di file (SHA-256, MD5, SHA-1) Calcola e confronta gli hash dei file nel browser per verificare i download. Calcolatore di subnet (CIDR, netmask, intervallo IP) Rete, broadcast, host utilizzabili e suddivisione in subnet per qualsiasi intervallo IPv4. Traduttore di espressioni cron Traduci le pianificazioni cron in linguaggio semplice e vedi le prossime esecuzioni. Riferimento dei codici di stato HTTP Cerca ogni codice di stato HTTP con una spiegazione semplice e una soluzione. Convertitore da cURL a JavaScript e Python Trasforma un comando curl in codice fetch e Python requests funzionante. Decodificatore di stringhe User-Agent Scopri browser, sistema operativo, dispositivo e motore da una stringa user-agent. Codificatore e decodificatore di entità HTML Converti i caratteri speciali in entità HTML e viceversa. Codificatore e decodificatore Base64 (testo e file) Codifica o decodifica Base64 e URL di dati, per testo e per file. Convertitore di colori (HEX, RGB, HSL, CMYK) Converti i colori tra HEX, RGB, HSL, HSV e CMYK, con selettore e contagocce. Generatore di UUID / GUID (v4 e v7) Genera lotti di UUID casuali sicuri, compresi i v7 ordinabili per tempo. Convertitore di basi numeriche (binario, ottale, decimale, esadecimale) Converti interi tra le basi da 2 a 36, di dimensione arbitraria. Generatore di intestazione Basic Auth Crea l'intestazione Authorization: Basic da nome utente e password. Calcolatore di alfa esadecimale (opacità in esadecimale) Converti percentuali di opacità in valori alfa esadecimali a due cifre, come 50% = 80. Generatore di tag meta viewport Crea un tag viewport corretto per pagine responsive. Generatore di tag HTML per favicon Genera i tag link e il manifest per le icone desktop e mobile. Costruttore di query string per URL Trasforma coppie chiave-valore in una query string URL correttamente codificata. Generatore di URL anti-cache Aggiungi un parametro di versione o di timestamp così i browser scaricano il file più recente. Controllo scadenza certificato SSL e promemoria Leggi un certificato, vedi quanti giorni restano e scarica promemoria per il calendario. Analizzatore di intestazioni e-mail Ricostruisci il percorso di un'e-mail, i ritardi e i risultati SPF, DKIM e DMARC. Generatore e validatore di robots.txt Crea un robots.txt o controlla errori di sintassi in uno esistente. Validatore e formattatore di sitemap XML Convalida una sitemap secondo lo standard e formattala. Anteprima Open Graph e condivisione social Vedi come appare un link su Facebook, X, LinkedIn e Slack e ottieni i meta tag. Generatore di box-shadow CSS Progetta visivamente ombre a più livelli e copia CSS pulito. Spiegazione e test di espressioni regolari Scomponi un'espressione regolare in parti in linguaggio semplice e provala dal vivo. Ricerca numeri di porta (porte TCP/UDP comuni) Scopri quale servizio usa una porta e quale porta usa un servizio. Ricerca tipi MIME (da estensione di file a Content-Type) Trova il Content-Type corretto per un'estensione di file, o l'estensione per un tipo MIME. Generatore di record SPF e DMARC Crea i record DNS TXT che impediscono ad altri di falsificare le e-mail del tuo dominio. Playground e guida rapida CSS Flexbox Prova le impostazioni di flexbox, vedi il risultato dal vivo e copia il CSS. Tester di firme webhook (HMAC SHA-256) Calcola firme webhook in stile GitHub, Stripe e Slack e verifica quella che hai ricevuto. Convertitore di font (da TTF/OTF a WOFF e viceversa) Converti un file font in WOFF per i siti web, oppure decomprimi WOFF in TTF/OTF. Formattatore e validatore JSON Formatta, minimizza, ordina e convalida JSON, con la posizione esatta dell'errore. Convertitore JSON, YAML e XML Converti tra JSON, YAML e XML in entrambe le direzioni. Formattatore e abbellitore SQL Rendi leggibili le query SQL con rientri e a capo. Tester di regex (JavaScript) Prova un'espressione regolare dal vivo: corrispondenze, gruppi e sostituzione. Anteprima Markdown (dal vivo) Vedi il Markdown renderizzato mentre scrivi e copia l'HTML. Minificatore di CSS, HTML e JSON Rimuovi commenti e spazi per rendere più piccoli CSS, HTML o JSON. Generatore di Lorem Ipsum Genera testo segnaposto per paragrafi, frasi o parole. Rilevatore del tipo di file (identifica qualsiasi file) Scopri cos'è davvero un file, dal suo contenuto e non dal nome. Generatore di albero di cartelle (struttura delle directory come testo) Trasforma una cartella o un elenco di percorsi in un albero di testo per la documentazione.

Domande frequenti

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
