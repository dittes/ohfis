Mescola righe a caso

Mescola un elenco in ordine casuale con un equo rimescolamento di Fisher-Yates.

Come funziona Mescola righe a caso

Randomise a list of names for a presentation order, shuffle quiz questions or mix a playlist. Paste one item per line and press "Shuffle again" as often as you like.

The tool uses the Fisher-Yates algorithm, the only simple method that gives every possible ordering exactly the same probability. Random numbers come from crypto.getRandomValues, the browser's cryptographically secure generator, with rejection sampling to avoid the slight bias of the common modulo trick. Sorting with a random comparator (a popular shortcut) is deliberately not used because it is measurably unfair.

Come si usa

  1. Paste your list, one item per line.

  2. Read the shuffled order.

  3. Press "Shuffle again" for a new order, then copy it.

Domande frequenti

Is the shuffle really random?

It uses the browser's secure random number generator and an unbiased algorithm, so every order is equally likely.

Can I pick a random winner instead?

Use the Name Picker Wheel in the Team tools to pick one or several names.

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
