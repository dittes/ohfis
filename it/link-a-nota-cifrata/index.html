Link a nota cifrata (messaggio privato)

Cifra un breve messaggio nel browser e condividilo come link più una chiave separata.

Caricamento dello strumento…

  • Nessun upload
  • Gratis
  • Nessun account
  • Funziona offline dopo il caricamento

Come funziona Link a nota cifrata (messaggio privato)

Share a password or a private message without leaving it readable in chat history. Write the note, and you get a link and, separately, a key (or use your own password). Send the two by different channels: whoever has both can read the note.

The message is encrypted in your browser with AES-256-GCM (Web Crypto). In "random key" mode a fresh 256-bit key is generated and shown separately; in "password" mode the key is derived from your password with PBKDF2-SHA-256 (210,000 iterations) and a random salt. The encrypted note is placed in the part of the link after the # sign, which browsers never send to servers, and this site stores nothing. The authentication tag makes any change to the note detectable. Honest limits: without a server there is no way to make the link self-destruct or limit how often it is opened, and the link length limits the message length.

Come si usa

  1. Write your message and choose a random key or a password.

  2. Send the link in one channel and the key or password in another.

  3. The recipient opens the link, enters the key and reads the note.

Domande frequenti

Can the note be deleted after reading?

No. There is no server that could delete it. Anyone with the link and the key can open it at any time.

Is it really private?

The text never leaves your browser unencrypted and is not stored by us. Its safety depends on sending the link and the key separately and on the strength of a password.

I miei file vengono caricati?

No. Il file viene aperto ed elaborato dal tuo browser. Puoi verificarlo tu stesso: apri la scheda Rete del browser mentre usi lo strumento oppure disconnettiti da internet dopo il caricamento della pagina.

Questo strumento è gratuito?

Sì, completamente. Nessuna registrazione, nessun piano a pagamento e nessuna filigrana sui tuoi file.
